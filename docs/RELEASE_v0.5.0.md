# AgentScribe v0.5.0 · 上下文翻译与录音可靠性

本版为源码预览版，包含源码和 Windows/macOS 安装脚本，不包含独立 EXE/DMG、模型权重或用户录音。

## 修复

- 后文触发重译失败时，保留同一原文上一版可用译文及失败提示；原文发生变化时不会误用旧原文的译文。
- 录音保存与翻译完成分开判断。存在翻译错误或缺失译文时保存为未完成，并显示“录音已保存 · 部分翻译未完成”；后续成功结果可清除错误。
- 加载本地录音时校验元数据结构、字幕字段类型、时间和重复标识。缺失或损坏字段显示可恢复错误，不改写原文件，也不破坏当前打开的记录。
- 翻译模型下载包含 HY-MT2 必需的独立对话模板；过滤分词器中模型不支持的 segment IDs。
- 忽略 SlideSpeech 数据集与原始音频压缩包，避免误纳入 Git 和发布文件。

## 功能与维护

- 新增 `tencent/Hy-MT2-1.8B`，采用现有 PyTorch/Transformers 环境。默认参考前 3 段、后 1 段原文，可调整或关闭；首版不强制等待后文，相邻上下文变化后自动修订。
- 上下文纳入翻译缓存键和过期结果检查。NLLB 保持逐句翻译。
- 本地文件夹工作区支持录音命名、自动保存、回听、删除与恢复；设置集中在左下角，改进窗口比例适配与显示。
- 偏好、录音状态、文件库启动、翻译调度及音频采集分离，增加依赖边界和回归测试。

## 验证与适用范围

149 项自动测试通过，覆盖本次三个缺陷的回归路径；改动 Python 文件静态检查通过。真实 Windows Qt 设置页面已检查。
HY-MT2 在 RTX 5070 Ti / CUDA / Transformers 4.57.6 上完成真实推理：上下文使示例中的 crane 从“起重机”改为“鹤”，bank 从“银行”改为“岸边”。这不是完整讲座的质量或端到端性能评测；macOS、CPU 和较小显存配置未完成本版同等实机验证。

解压 `AgentScribe-v0.5.0-source.zip` 后按 README 安装。已有模型需自行保留或重新准备；录音目录和旧启动入口保持兼容。
`SHA256SUMS.txt` 提供源码压缩包校验值。模型和数据集适用各自许可，见 THIRD_PARTY_NOTICES.md。
