# 界面与交互体验

## 常用操作

- 首页底部显示当前原文/翻译语言与识别引擎，点击即可进入对应设置。切换到仅原文时，快捷入口同步显示状态。
- 设置采用独立侧栏和内容页，每页开头介绍用途。模型页把引擎与设备放在前面，本地 Whisper 权重导入通过展开项进入。
- 搜索忽略大小写和首尾空格，支持多个关键词，例如 `HY-MT2 前文`。无结果时提供清除搜索入口。
- “使用指南”介绍准备环境、选择来源与语言、按需翻译、字幕状态和录音整理，并提供设置跳转。
- “跟随最新字幕”在设置和更多菜单中同步；不会出现两处勾选状态不一致。
- 新建录音、新建文件夹、重命名、最近删除和音频实验室共用弹窗视觉。空白名称不能提交；取消弹窗不会创建文件。
- 最近删除为空时显示说明；恢复与永久删除使用不同按钮层级，永久删除仍需确认。

## 动态效果与键盘

- 设置切页约 150 ms 渐显，开关约 150 ms 滑动，支持的平台上弹窗约 140 ms 渐显。
- “常规 → 减少动态效果”会持久保存并关闭上述动画。字幕始终按实际识别事件更新，没有模拟打字。
- `Ctrl+,` 打开设置；设置内 `Ctrl+F` 聚焦搜索；`Ctrl+N` 新建录音；设置内 `Esc` 返回录音，弹窗内 `Esc` 取消弹窗。
- 保留键盘焦点样式，开关与关闭按钮具有可访问名称。

## 验证与边界

本轮在 Windows / Python 3.12 / PySide6 上检查。完整模拟回归 182 项通过，2 项 Mac 专用测试跳过；新增独立 Qt 进程回归覆盖搜索、无结果恢复、指南跳转、菜单同步、快捷返回、空白名称与动画偏好持久化。改动 Python 文件 Ruff 通过；全仓库既有静态告警未纳入本次清理。

`scripts/preview_ui.py` 用独立示例库渲染真实 Qt 窗口，显式阻止原生音频导入。截图位于 `.work/ui-experience/`；包含普通、窄和宽窗口，设置页、菜单、新建录音、最近删除与音频实验室。使用 `--interactive` 可保留预览窗口用于交互检查。预览不加载识别模型或访问声卡。

本轮没有改动 ASR、SaT、翻译或录音存储算法；SaT 继续是必需依赖。UI 验证不代表重新验收真实音频、模型质量或 macOS 原生窗口效果。
