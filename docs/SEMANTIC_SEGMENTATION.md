# SaT 上下文分句

SaT 是字幕链路必需的内部文本边界组件，固定在 CPU 上运行。安装推理环境或下载 / 检查识别模型会一起准备它的权重和分词器，不再提供独立准备按钮、设备和首次提交等待设置；旧的 `semantic_device`、`semantic_lookahead` 偏好不再生效。内部首次提交等待保持 3 秒，识别与翻译仍独立选择计算设备。模型准备完成后推理无需联网。

会话首先加载 SaT，成功后才继续准备识别链路；所有模型就绪后开始采集。SaT 缺失或加载失败会阻止启动，并提示准备模型。推理异常会报告错误并停止会话，已经显示的原文保留。

macOS / ONNX Runtime 1.30+ 在“准备 / 检查 SaT 分句模型”时另存一份 CPU ORT 图到 `.work/cache/sat-ort/`，约 449 MiB，不覆盖下载的原始权重。之后启动通过 ORT 内存映射直接引用初始化权重，减少加载时的临时复制；分句阈值、分词器和边界规则不变。机制见 [ONNX Runtime 配置定义](https://github.com/microsoft/onnxruntime/blob/v1.30.0/include/onnxruntime/core/session/onnxruntime_session_options_config_keys.h)。

缓存按运行库版本、机器架构和本地权重标识隔离，完成标记在文件写好后才发布。已有安装可重新点击准备按钮生成缓存；开始聆听时只读取缓存，不转换模型。没有兼容的完整缓存、较旧运行库或其他平台沿用原始 ONNX 加载。缓存损坏导致实际载入失败时报告模型错误，可重新准备修复；不把推理错误忽略掉。准备缓存本身需要一次较高的内存峰值，属于模型准备阶段，不能算成聆听启动内存降低。

## 从文本到字幕

1. ASR 只提供原文、修订版本及已确认字符范围，不决定字幕句子边界。
2. SaT 根据清理过的文本副本返回字符边界，再映射到原文位置。较长输入通过重叠窗口处理；相同文本复用预测结果。
3. 字幕管理按 SaT 候选边界生成暂定分段，原样保留字符。边界内文字处于 ASR 确认区时可以提交初译；稳定但没有内部边界的尾段保持 3 秒首次提交等待。提交并不冻结切分：SaT 新增、撤回断点时允许拆分、合并和重译，删除事件使对应旧任务失效。
4. **ASR 已确认对应文字是 SaT 收尾的必要条件。** 在此前提下，内部断点需在两个不同文本上下文中保留，并具有至少 4 个已确认的后文单位（英文词或汉字），才成为最终边界。重复轮询相同文本不增加边界证据。这里的后文数量是边界判断条件，不是最短字幕长度。
5. 没有后文的最后一段保留初译，直到后文确认其内部边界，或停止聆听完成 ASR 尾部识别后由 SaT 收尾。停止信号自身不能把未确认的 ASR 文字标为定稿。
6. 原文最终状态必须同时满足 `asr_final` 与 `boundary_final`。翻译速度和成功与否不参与判断；HY 最终译文还必须匹配当前原文和切分版本。

| 状态 | 行为 |
| --- | --- |
| 未提交 | 展示识别内容，等待确认范围与分句或尾部等待条件 |
| 已提交，可修订 | 提交、ASR 改字或 SaT 重切触发小上下文初译，默认参考前 1 段已定稿原文；保留已有译文并标记其来源 |
| ASR 已确认，SaT 未收尾 | 可初译和重切；仍不能请求最终翻译 |
| ASR 与 SaT 均已确认 | 请求当前版本的最终翻译，默认参考前 10 段、后 1 段已定稿原文；相邻待译内容可共享背景合并 |

Windows 的 PyTorch Qwen 与 macOS 的 MLX Qwen 均使用 `qwen_accurate.QwenAccurateOnline`、`asr_stability.StablePrefix` 和同一个 `RevisionStore`。模型适配只负责加载和一次 PCM 到字符串的推理；旧快/准确模式值保留在历史配置中，不再选择另一套提交策略。Whisper 也使用同一 SaT 与翻译规则，ASR 确认范围来自它自己的输出契约。

Qwen 默认至少 3 次随音频推进的识别，并跨越 4 秒观察范围，才确认一致前缀；末尾 4 个文字单位继续保留修订空间。新词单独积累证据，重复识别同一份 PCM、复制旧窗口前文及墙钟等待不能增加确认。真实话语结束、明确暂停与 EOF 的最终解码可以确认剩余文字，但不会自动确认 SaT 句子边界。

短 VAD 停顿保留音频上下文，恢复说话时加入实际静音采样，再整体识别。连续静音 PCM 进度达到 3 秒时才结束 ASR 话语；没有继续送入音频时，墙钟等待不能关闭它。容量上限只推进窗口：在约 30 秒窗口后保留至少 5 秒重叠音频，重新识别并对齐可修订尾部，不设置话语 `closed`，也不确认整段。如果积压使部分旧音频只有一次识别证据，则其复制前缀继续保持未确认，等待真实结束收尾。

Qwen 共用会话的 `qwen_window_seconds`（默认 30 秒），限制为 8–40 秒，额外观察最多 5 秒；MLX 子进程相应接受最多 45 秒 PCM。重叠拼接只使用识别原文，不生成替代词；找不到可靠词语锚点时采用估计位置并保留未确认尾部。词时间与重叠音频位置仍为估计值，不适合精密对齐。显式暂停按已接受 PCM 的终点结束话语，后续录音不受旧结束请求影响。

ASR 音频终点和句号不再补充 SaT 文本断点。逗号、分号、冒号、顿号后的 SaT 候选断点仍暂不采用。后文纠正最后一条切分时，无论原文是否有句号，都可重新打开并合并；ASR 改字或撤回确认范围时也重新打开受影响字幕。更早已确认且未变的文字保持稳定，历史改字会将比较范围移回实际受影响位置。

SaT 修订优先于尚未开始的 HY 工作：字幕更新完成前，消费者不启动下一个翻译请求；已开始的推理不强行中断，发布时检查其有效性。同一字幕范围只保留最新待处理请求，拆分/合并时删除失效范围；每次请求绑定原文和切分版本。ASR 改字或 SaT 重切都会重新翻译，旧结果不得覆盖新状态或提前定稿。详见 [上下文翻译](CONTEXT_TRANSLATION.md)。

SaT 是边界预测器，不是句子完整性验证器。模型对输入末尾的高概率不能证明半句话已经完整；实现不采用该概率来收尾。等待更多上下文能减少提前锁定，但不能保证没有错误断点。

## 能力范围

### SaT 输入副本的标点清理

仅在 `semantic_model.py` 内清理供模型判断的副本，保持大小写和 0.5 阈值。移除普通中英文标点；保护词内撇号、连字符、下划线、数字间小数点、数字前负号，以及常见点式缩写、称谓、HTTP(S) 网址和邮箱。英文词之间缺少空格时用分隔空格替代标点，避免 `hello,world` 粘词；相邻中日韩文字之间不额外插入空格。特殊文本保护是有限规则，不覆盖全部专业记法。

预测位置映射回 ASR 原文，保留原来的词语、大小写和标点；句末标点留在前段，开引号/括号尽量保留在后段。字幕呈现、翻译输入和录音保存仍使用原文片段，不使用清理副本。合并后的句子可能仍含 ASR 的错误句号，此功能不重写标点。

清理对所有输入语言生效。本地英语课堂对照显示部分碎句减少，但中文及合法短句可能过度合并；不能据此承诺整体准确率提升。标点清理沿用上述提交、定稿和 ASR 段终点规则；翻译请求调度见 [上下文翻译](CONTEXT_TRANSLATION.md)。

SaT 只预测文本切分位置，不改写、补全原文，也不恢复 ASR 已经漏掉的词。它不分析音频停顿或说话人轮次，不改变上游识别窗口和音频提交策略。

“Qwen 原文草稿刷新目标”默认 0.5 秒，表示请求频率，实际更新受推理耗时限制；Whisper 保留自己的更新节奏。可修订草稿经过同一字幕映射链路显示。

回归覆盖模型边界、短句、长文本、等待后文、稳定定稿、原文纠正、尾部撤回、字符保留和模型异常。真实课堂的边界质量与端到端延迟仍需使用录音评估。
