# 根据上下文分段

“Qwen 原文草稿刷新目标”默认 0.5 秒，同时配置 Qwen 的音频合并和内核更新周期；Whisper 保留原有更新节奏。它表示请求频率，不保证每次只有一个词或每 0.5 秒完成推理。每份真实草稿直接显示，不等待语义分段，不播放假打字动画。原文替换会短暂显示“旧词 → 新词”；撤回的分段被并入另一段时显示合并提示。课堂推荐点击“课堂逐词草稿 · 保留短停顿”，同时将 Qwen 检测器的静音阈值设为 1.5 秒，保留短暂停顿的上下文。实测见 [课堂回归](CLASSROOM_VALIDATION.md)。

在“模型管理 → 字幕与延迟”点击准备/检查 SaT，安装可选组件并下载本地分句权重（约 408 MiB，另有分词器）。默认优先使用 SaT；不可用时诊断记录明确提示回退到上下文规则。准备完成后的推理无需联网。分句设备可以选择 CPU 或 NVIDIA CUDA，识别和翻译设备独立配置。

| 状态 | 行为 |
| --- | --- |
| 听写中 | 展示识别内容，继续等待表达边界 |
| 暂定分段 | 稳定识别内容可以先翻译，原文和译文仍可修订 |
| 已定稿 | 后续稳定上下文和重复观察支持锁定前缀；停止聆听时收尾 |

默认观察 3 秒后文，显示段落上限为 12 秒。后文时长指识别时间戳，不是静音等待时间。显示过长时换段，但不据此断言表达完整；显示切分需更长后文才锁定。两项参数均可调整。

例如“这个公式的前提是……我们先看右边这个图”，可以在话题转向处暂定分段，不会凭空补上老师未说出的条件。“The value is five. Actually it is six.”中的纠正会保留在同一可修订段落。旧翻译任务被新版本替换，计算中的旧译文也必须匹配当前原文才会显示。

SaT 是文本边界预测模型，并非能判断所有课堂意图的大语言模型。未完表达、纠正与话题转向还结合规则处理；它不恢复 ASR 已经漏掉的词，也不改变上游识别的音频提交策略。上游确实纠正原文时，即使旧字幕已定稿，也允许更高版本修正它。

回归覆盖停顿不定稿、后文稳定、未完句转向、原文纠正、尾部撤回、字符保留和翻译版本合并。真实课堂录音仍需对照回听评估，不能以短音频冒烟测试代替质量验收。
