# AgentScribe 0.8.0 · 源码集成说明

按用户要求，将本轮共享操作完善、原生更新接入和连续录音初译修复集成到 `main`，统一源码版本为 `0.8.0`。本次交付为源码上传，不构建安装包、不创建发行标签或 GitHub Release，也不推进更新订阅；下载入口继续指向已发布的 beta.2。

## 本轮变化

- 模型未指定或缺失时显示准备引导，提供推荐模型下载和录音保存位置选择；已有模型就绪时不重复弹出。
- 模型、下载、保存和更新结果统一为右对齐轻量弹窗，不占正文布局；进度刷新不反复打开弹窗，修正圆角外侧黑边。
- 录音音量条随可用宽度伸缩，空闲隐藏；保留磨砂外圈、不透明正文及白色/深色主题。
- 回放按已有字幕时间高亮和滚动跟随，支持拖动定位、手动浏览和恢复跟随；增加字幕搜索及关闭当前录音入口，关闭前等待保存。
- 用户明确更改保存位置时后台复制、校验完整录音库，再切换路径与清理未变化原件；取消或失败保留原文件。
- Mac 接入 Sparkle，Windows 接入 WinSparkle / Inno Setup；共享安装门禁等待录音、保存和自有进程释放。加入完整旧程序备份、启动健康检查与有归属校验的失败恢复。
- 提供两端锁定载荷构建、签名校验、Release 草稿和更新订阅工作流；本地与 CI 调用同一套构建脚本。
- 修复连续录音初译等待整个 ASR 前缀确认而迟迟不入队的问题：SaT 在两次不同上下文中保留同一分句且持续既有 3 秒观察期未变时可提交初译，心跳不能作为新观察。ASR 窗口与确认阈值、双重确认定稿、固定翻译上下文保持不变。

## 验证与交付边界

本轮版本同步后完整无音频回归 **913 项通过，182.86 秒**，零原生音频导入尝试；Ruff、暂存差异空白、版本一致性与工作流 YAML 解析通过。执行环境为 Mac，不能代替 Windows 实机验收。

历史原生界面、隔离 Mac 更新/恢复及真实文件推理证据与适用范围见 [VALIDATION](VALIDATION.md)。初译修复的同一 100 秒录音对照，两轮均通过完整最终翻译，候选在停止前持续发布初译；每个候选仅测一次，不代表质量或性能结论。

发行工作流本轮随源码上传，尚未执行远程安装包构建。生产 CI 私钥、GitHub Pages 更新订阅、Mac Developer ID / 公证和 Windows Authenticode 尚待部署；Windows 原生构建、安装升级、两端真实录音/回听及长会话仍需验收。已有隔离 Mac 测试不能代替正式签名安装包验收。依赖声明与打包锁一致性、新增顶层目录遗漏检查及完整安装包功能检查仍不完整，详见 [发行流程](RELEASING.md)。
