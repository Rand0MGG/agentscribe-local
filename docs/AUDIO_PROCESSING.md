# 音频实验室

侧栏“音频实验室 · 增强与回听”提供五个预设及高级参数，默认原声直通。

1. 确认“录制来源”：麦克风录讲话，系统声音录电脑播放内容。
2. 录制 3–60 秒并观察输入电平，或导入不超过 60 秒的 WAV。
3. 处理样本，分别回听原声和 ASR 输入。更改参数后须重新处理，避免播放旧结果。
4. “应用到聆听”保存处理参数，并同步所选来源到主界面。

录制时停止播放，避免扬声器回灌。录制和处理文件随实验室关闭删除；导入原文件和显式导出的文件保留。

## 路径与预设

48 kHz 连续采集 → WebRTC APM/低频清理 → 在线 NARA-WPE → DeepFilterNet3 → EQ/AGC/峰值保护 → 连续重采样到 16 kHz → ASR。

每级可关闭并保留跨块状态，结束时补齐尾音。实验室与聆听调用同一处理器。声道质量选择未实现，保留原有混音行为。

- 普通麦克风：低级别 APM、有限 AGC、峰值保护。
- 嘈杂环境：DF3 混合原声、AGC、峰值保护。
- 课堂远场：增加 WPE，单声道估计效果依赖房间和录音。
- 组合增强：APM + WPE + DF3，需要谨慎试听轻声损失。
- 高级参数包括 NS 级别、WPE 预测/记忆参数、WPE/DF3 混合比例、响度、EQ 和峰值上限。

APM、WPE 和响度使用现有 CPU 实现。DF3 可选 CPU 或 NVIDIA CUDA；macOS 尚未实机验收，CUDA 不适用。使用社区的 stateful ONNX 导出，部分算子由 ONNX Runtime 在 CPU 执行。模型很小，GPU 不保证比 CPU 快。声音变好听不必然代表识别率上升，需在真实课堂样本上比较原文。

## 安装与恢复

“准备增强组件”将固定版本依赖装到 `.venv-wlk`，校验并准备 DF3 模型。CUDA 12 后端隔离在 `audio-cuda-1.23.2`，不覆盖 ASR 的 CPU ONNX Runtime。聆听时只加载校验通过的本地模型。

安装和模型检查显示阶段、耗时，支持取消和关闭。模型加载检查最多 120 秒。取消保留已下载文件，可重试准备。CUDA 初始化失败不会冒充 CPU 成功。

原声全零会提示来源/静音/权限问题，不再当作处理成功。聆听中连续 3 秒全零也会提示。非有限采样、非法参数提前拒绝。WPE 加入功率下限、协方差约束和异常频点保护，防止长静音和 APM 抑制后数值失稳。

## 2026-09-09 修复证据

- 本次用户遗留的 15 秒原声及处理结果均全零，无声发生在增强之前。
- 旧 CUDA 13 运行库与 PyTorch CUDA 12 不匹配，改用独立固定版本。
- DF3 导出含 CUDA 不支持的 `FusedConv(Sigmoid)`；加载时展开为等价 Conv + Sigmoid，不修改缓存权重。
- 五个预设 CPU/CUDA 均通过实际输出、分块一致性、时长和尾部检查；取消、关闭和超时恢复有 Qt 子进程回归测试。

使用 `.venv-wlk` Python 运行 `scripts/smoke_audio.py --device cpu` 或 `--device cuda` 可复查。自编语音 fixture 验证不等同于真实课堂准确率验收。
