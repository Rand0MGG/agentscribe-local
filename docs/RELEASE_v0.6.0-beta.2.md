# AgentScribe 0.6.0-beta.2 · Mac 模型引导与版本更新

本版只提供 Apple Silicon / macOS 15 及以上的 DMG，继续作为预览版发布。版本、标签 `v0.6.0-beta.2` 与安装包对应同一个审核后的 main 提交；旧版安装包保留。Windows 无本版安装包，未完成 Windows 实机验收。

## 使用上的变化

- 主界面增加“准备识别与翻译模型”：推荐固定 Qwen3-ASR 1.7B MLX 4-bit 与 HY-MT2 1.8B Q4_K_M / Metal；首次缺文件时给出准备提示。环境、模型及字幕分句组件沿用生产安装器，已有兼容文件复用，不包含在 DMG 中。
- 下载显示文件或字节进度、速度及可用的剩余时间估计，可取消并保留缓存；普通设置默认只显示常规、聆听和使用指南，其他设置可展开。没有内存自动检测或按内存选择模型。
- 固定翻译上下文：初译参考前后各 1 段已有定稿原文，最终翻译参考前 5 后 1 段，不等待尚未出现的后文。ASR 窗口、确认与原文定稿算法保持不变。
- 聆听中设置可修改并保存，当前会话继续使用原快照，下次生效；课程后台退出等待移到工作线程，等待时界面继续响应，并保护仍被占用的文件。
- Mac 系统菜单提供关于、版本与更新、检查更新，显示当前版本。启动后后台检查当前平台/渠道的发布，有新版时显示可稍后处理的提示；无更新或离线不打扰，不占用模型准备任务、不停止录音。
- 移除包内 Node 开发头文件和 man 手册，保留 Node/npm、Qt/WebEngine、Python 与许可；DMG 约 315 MB。完整运行组件仍是主要体积来源。

## 安装与升级

从 [发行页](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.6.0-beta.2) 下载 DMG，将 AgentScribe.app 拖入 Applications。升级前结束录音并正常退出旧程序，再替换应用。用户的录音、偏好、模型和运行组件保留在应用包之外，不需因应用版本变化重新下载兼容模型。

更新检查目前引导到发行页，尚未实现自动下载安装、Sparkle/WinSparkle 或签名 appcast；旧 beta.1 没有启动检查，需手动安装本版后获得该入口。

## 签名与验证边界

继续使用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；系统阻止打开时，核对项目来源后按“系统设置 → 隐私与安全性 → 仍要打开”操作，不关闭系统安全保护。模型需要首次联网准备与额外空间；建议预留至少 20 GB。

本轮 Apple M2 / macOS 26.6.2 的 704 项无音频回归及 Ruff 通过，覆盖固定上下文、旧配置、下载进度、界面响应、Cocoa 原生菜单、非模态新版提示和迟到结果。安装包沿用生产构建脚本、固定依赖和独立包探针，清单记录源码提交、文件摘要、签名及 DMG SHA256。包内容与复现步骤参照 [beta.1 包结构和构建说明](RELEASE_v0.6.0-beta.1.md#复现构建)。

本轮未重新下载真实 Qwen/HY 权重、未重测推理质量或性能；真实音频权限、采集/回听、长课堂、其他 Mac 及 Windows 实机仍待验收。模拟测试不证明所有操作都不会阻塞。应用源码尚未指定开源许可证，随包组件保持各自许可。
