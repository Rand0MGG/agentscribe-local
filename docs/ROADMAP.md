## 持续改进主线

当前按用户要求优先改善 **UI 使用体验**。每轮选一个实际使用流程，持续完成问题定位、必要修改和验收；其余主线保留待办，直接影响该流程的可靠性问题一起处理，不为凑批次混入无关修改。

| 主线 | 要达到的用户结果 | 当前关联任务 |
| --- | --- | --- |
| UI 使用体验（当前首要） | 操作入口容易找到，字幕易读，状态和下一步清楚，失败可恢复，常用窗口尺寸下顺畅操作 | R19 及其余 P1 跟踪修复后的平台验收；界面问题归 R18、检查反馈归 R13 |
| 录音与数据可靠性 | 减少崩溃，保存失败可重试，异常退出后能恢复已落盘内容 | R8、R16、R23 |
| 实时字幕质量与性能 | 识别、分句和译文可靠，延迟与资源可控，长课堂不持续积压 | R3、R4、R6、R9 |
| 安装、更新与发行 | 安装/准备/升级可完成，失败可恢复，数据和模型保留 | R2、R14、R15、R24 |
| 课程资料与笔记 | 课件可阅读、术语有效、笔记来源可靠，云用途和成本可控 | R5、R10–R12、R17 |

两端验收随各主线推进，R1 跟踪既有 Mac 验收缺口；文档、测试和 R7 辅助工具维护支撑实际任务，不另立产品方向。UI 行为维护于 [UI_DESIGN](UI_DESIGN.md)，Qt 作为当前默认入口与迁移基线，Electron 复用业务并对照原有组件契约。
