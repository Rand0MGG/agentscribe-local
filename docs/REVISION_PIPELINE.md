# Qwen 修订通路

快速 Qwen 路径通过项目内适配器捕获第三方 streamer 返回的完整 hypothesis，以及 flush 的 final_text。它不修改安装目录，不改变模型、音频输入或推理参数。适配器捕获的并非模型 logits，也无法恢复第三方 streamer 在返回之前已经丢弃的内容。

每个会话拥有独立标识；每个上游 utterance（包括其内部窗口切换）拥有区间标识和递增版本。新版本完整替换同一区间旧文本，支持缩短、清空和收尾纠正。底层只追加 token 的通路仍供 WLK 内部调度使用，但不会作为 Qwen 字幕文本来源。独立修订通知避免 WLK 抑制无新增文字的响应。

分句不再使用不完整句关键词、话题切换表达式、纠正表达式或领域搭配规则。SaT 提供显示候选，失败时退回标点与长度排版。显示换段不再额外要求 12 秒后文；通用后文观察和 0.8 秒稳定条件保留，已有字幕仍可被纠正。字符时间为近似插值，不能用于宣称逐词延迟。

翻译队列合并待执行版本，执行前与返回后均检查原文版本；已开始的推理不能撤销，但其过期结果不会发布。

## 诊断证据

`scripts/replay_streaming.py run` 开启诊断，在 `events.jsonl` 中分别保存 `model_result` 与 `caption` 事件。普通桌面会话默认关闭原文诊断记录。直接运行 worker 时可显式设置 `LINGUAFLOW_TRACE_REVISIONS=1`。

完成回放后生成：

- `model-final.txt`：每个区间最后有效模型文本，含重复与标点。
- `captions-final.txt`：撤回和版本替换后的字幕文本。
- `revision-audit.json`：只忽略空白的比较结果，以及差异对应的字符范围、模型区间/版本和字幕 ID/版本。范围以去掉空白后的文本计数。

`match` 仅说明字幕未额外修改最终模型文字，不代表识别正确。失败、中断、缺少区间关闭或缺少正常结束证据只能标记为不完整，不得当作匹配验收。异常退出时可能只有原始事件和未完成 manifest；使用 `linguaflow.revision_audit.write_audit` 可从该目录重建不完整报告。

本轮只进行功能回归和短音频验证，没有开展整场 WER 比较或宣称准确率提升。
