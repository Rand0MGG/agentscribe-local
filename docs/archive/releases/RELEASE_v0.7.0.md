# AgentScribe 0.7.0 · 源码集成说明

按用户要求，统一源码版本正式进入 `0.7.0`，不带 beta 后缀。本轮将当前已完成的 Mac 适配与电脑音频修复集成到 `main`；这是源码版本说明，不是安装包发布公告。没有构建安装包、创建发行标签或 GitHub Release；下载入口仍指向已发布的 beta.2。

## 本轮变化

- 两端共用磨砂背景组件，壁纸读取与模糊合成移到后台，绘制仅使用缓存；主题、尺寸或屏幕变化时合并任务并拒绝旧结果。
- Mac Qt 6.9+ 的共享背景延伸至原生标题区域，隐藏重复系统标题，保留红黄绿按钮、缩放与全屏；旧 Qt 保留原生标题栏。
- Mac 壁纸跟随窗口所在屏幕；悬浮字幕配置桌面空间和全屏辅助窗口策略。两端重新打开悬浮窗口时校正屏幕外位置。
- Mac 增加“系统音频 · 电脑声音”，通过按需导入的 ScreenCaptureKit 采集，无需 BlackHole。设备选择、会话、暂停、切换和保存仍为共享实现；Windows 保持原有 WASAPI 路径。
- Mac 桌面依赖与安装包锁增加固定版本 PyObjC 桥接；Windows 与推理环境不安装。许可说明及音频测试守卫同步更新。

继承已有共享模型管理、白色/深色主题、固定翻译上下文及 SRT/TXT/Markdown 导出。ASR 窗口、识别确认和定稿参数未因本轮适配而调整。

## 验证与交付边界

Mac UI 的原生窗口检查、完整模拟回归及电脑音频短采集证据见 [MACOS_SUPPORT](../testing/MACOS_SUPPORT_20261011.md)。真实电脑音频探针确认 PCM、暂停/继续、来源切换、资源释放和 WAV 保存；探针使用模拟推理，不代表与 GPU 模型联动或安装包权限验收。

首次安装态授权、真实麦克风、回听、长会话、其他 Mac、Windows 硬件和旧安装包升级仍待对应验收。当前构建默认 ad-hoc 签名，Developer ID、公证及应用内下载安装尚未完成。源码版本变更不替代这些交付检查。

首次打开引导、统一轻量反馈、音量图改进、回放高亮与跟随、更改保存目录自动迁移、关闭当前录音等已确认需求，仅记录为 [待实施交互](../../UI_DESIGN.md#录音与回放)，不包含在本轮功能代码中。用户确认的其他操作完善项也在该节统一维护。
