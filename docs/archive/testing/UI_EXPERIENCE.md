# 界面与交互体验

## 常用操作

- 首页底部显示当前原文/翻译语言与识别引擎，点击即可进入对应设置。切换到仅原文时，快捷入口同步显示状态。
- 设置采用独立侧栏和内容页，每页开头介绍用途。模型页把引擎与设备放在前面，本地 Whisper 权重导入通过展开项进入。
- 搜索忽略大小写和首尾空格，支持多个关键词，例如 `HY-MT2 前文`。无结果时提供清除搜索入口。
- “使用指南”介绍准备环境、选择来源与语言、按需翻译、字幕状态和录音整理，并提供设置跳转。
- 字幕在底部时自动跟随。向上滚动或拖动滚动条离开底部后暂停；浮动的圆形向下箭头返回最新字幕，自行滚到底部也会恢复跟随。设置和更多菜单不再提供独立开关。
- 首页底部录音控制区直接显示“音频来源”和刷新按钮，与设置页的来源选择同步。启动、聆听、暂停和收尾期间锁定两处选择，停止完成后恢复。
- 聆听时可点击“暂停”，采集退出后显示“继续录音”。暂停期间已有字幕继续处理；继续后接着写入同一份录音。也可在暂停时停止或关闭。实现与验收边界见 [暂停测试](../../testing/RECORDING_PAUSE.md)。
- 暂停跟随时，前面字幕的译文更新尽量保留当前阅读位置；已经被 200 张卡片上限移除的内容无法继续作为阅读锚点。
- 新建录音、新建文件夹、重命名和最近删除共用弹窗视觉。空白名称不能提交；取消弹窗不会创建文件。
- 音频处理在后台自动完成，设置中不再提供音频实验室、预设和高级处理参数。录音回听继续通过录音工作区使用。
- 最近删除为空时显示说明；恢复与永久删除使用不同按钮层级，永久删除仍需确认。

## 动态效果与键盘

- 设置切页约 150 ms 渐显，开关约 150 ms 滑动，支持的平台上弹窗约 140 ms 渐显。
- 新增字幕或译文使内容增高时，视口以约 16 ms 的更新间隔平滑追踪底部；连续更新改变目标位置，不重启动画。滚轮、滚动条和滚动键立即打断跟随。
- “常规 → 减少动态效果”会持久保存并关闭上述动画与字幕平滑滚动；仍保留自动跟随行为。字幕始终按实际识别事件更新，没有模拟打字。
- `Ctrl+,` 打开设置；设置内 `Ctrl+F` 聚焦搜索；`Ctrl+N` 新建录音；设置内 `Esc` 返回录音，弹窗内 `Esc` 取消弹窗。macOS 对应 Command，界面提示使用 Qt 原生快捷键显示。
- 保留键盘焦点样式，开关与关闭按钮具有可访问名称。

## macOS 兼容复核（2026-09-29）

范围包括今日的设置/菜单/弹窗、自动跟随与来源选择，以及共享的提交定稿、翻译调度、VAD Float32 修复和 SaT 输入副本清理。

- 新 UI 通过 Qt 控件、绘制和定时器实现，没有新增 Windows 原生依赖。主窗口的 Windows 材质与标题栏仍有平台条件。
- 修复零位移触控板事件打断返回底部动画：只在滚轮事件带有实际纵向位移时暂停跟随。像素位移、自然滚动方向和惯性移动仍交给 Qt。依据：[QWheelEvent](https://doc.qt.io/qt-6/qwheelevent.html)。合成事件回归覆盖开始、更新、惯性、结束及两种 inverted 标志，修复前可复现 ScrollEnd 取消跟随。
- 设置快捷键提示改用 `QKeySequence.NativeText`；Qt 在 Apple 平台将 Ctrl 组合映射到 Command。依据：[QKeySequence](https://doc.qt.io/qt-6/qkeysequence.html)。
- 音频来源复用原有 CoreAudio 输入列表。模拟 darwin 回归覆盖 Mac 麦克风/BlackHole 的选择同步、会话配置、刷新重排、断开和启动/聆听/停止期间锁定。BlackHole 保持普通输入（loopback=False），没有新增原生系统声音捕获。
- SaT 清理与偏移映射只用 Python 标准库；Mac 仍使用 SaT CPU，MLX ASR 独立使用 Apple GPU。原文提交/定稿与翻译调度的共享层没有新增 CUDA 或 Windows 限制，未更改 MLX 进程协议。

本次执行环境是 Windows 11 / AMD64 / Python 3.12.8。针对性无音频测试 53 项通过；修复后完整回归 229 项通过、2 项 Mac 专用测试跳过，未发现原生音频导入尝试。修改文件 Ruff 通过。模拟 darwin 和合成触控板事件不等于 Mac 实测；仍需在 Mac 检查真实触控板、Retina 显示、原生菜单/透明弹窗、Command 快捷键，以及今日更新后的 MLX/SaT/翻译完整链路。安全复核命令：`.venv/bin/python scripts/test_no_audio.py -q`；独立无音频预览：`.venv/bin/python scripts/preview_caption_follow.py`。


2026-09-29 已在实体 M2 Mac 上完成本轮无音频回归、Cocoa / Retina 窗口和 Command 快捷键检查，并验证最新主线的 MLX + SaT 文件链路。字体修复、结果及待验收范围见 [Mac 主线同步验证](MACOS_MAIN_SYNC.md)。

2026-10-03 自动检查额外发现 Windows / Python 3.11 在非中文 locale 下将中文直接传给 `strftime()` 会导致默认命名失败。文件库和新建对话框现共用不经过 locale 格式化的中文默认名称；日期格式保持原样，旧文件不重命名。保存收尾期间继续禁用录音操作，嵌套 Qt 保存等待结束后再安排会话对象释放，未完成的磁盘写入继续持有录音锁。动画回归使用可控帧时间检验原有中间位置及手动中断断言，避免依赖 CI 主机在固定 70 ms 内调度计时器。
