# 上下文翻译

在设置 → 翻译模型中选择 `tencent/Hy-MT2-1.8B`，下载 / 检查模型后开始录音。
也可以选择完整本地模型目录。已有 NLLB 偏好不会被替换。

HY-MT2 默认参考前 3 段、后 1 段原文。前文可设 0–6 段，后文可设 0–2 段；0 表示不参考。
这些设置在下一次录音生效，只用于最终翻译。每段首次提交生成无上下文初译；之后原文如何修订都不追加翻译请求。原文由 ASR 独立定稿时，捕获当时可用的稳定前后文，生成一次最终译文。缺少后文不等待，邻段以后变化也不再触发重译。停止录音处理剩余原文并排空翻译队列。

只参考已定稿或整段处于 ASR 稳定区的原文，不使用逐字变化的草稿。“曾经提交过”本身不代表当前修订已稳定。每段前文最多保留末尾 600 字符，后文最多保留开头 600 字符；当前待译原文不截断。
上下文只包含源文，避免把旧译文的错误反复强化。提示词明确区分背景和当前待译段，要求只输出当前段译文。
模型指令遵循不是形式保证；仍需真实录音评测重复、漏译及上下文带来的收益。

NLLB 保持逐句翻译，上下文选项不可用。它不是指令模型，直接拼接前后文会破坏字幕段落对应关系。

## 实现边界

- `translation_context.py`：首次与最终请求快照、冻结上下文、请求有效性，不依赖模型或界面。
- `translation_service.py`：串行推理、包含上下文的缓存键，以及发布时的请求和上下文双重检查。
- `translation_models.py`：本地模型配置识别、目标语言名称和背景提示词。
- `backends.py`：NLLB 与 HY-MT2 的独立模型适配器，重型依赖延迟导入。
- `wlk_worker.py`：在字幕状态锁内更新上下文并排队；推理期间不持有字幕锁。

正常生命周期最多两次请求；最终任务替换尚未开始的初译任务，相同原文、语言和上下文复用缓存，因此实际模型调用可能只有一次。未定稿字幕合并保留最早一条的初译请求，不追加初译。若 ASR 明确推翻已定稿原文，或后文纠正了最后一条的断句，则开启新的修订周期，不受“两次”的限制。翻译失败保留已有初译和原文，标记未完成；空输出也视作失败。本轮没有加入自动重试。

界面标明“初译 · 原文已更新”“初译 · 等待最终译文”或“译文已定稿”。`Caption.translation_phase` 与 `translation_source` 随录音保存；旧录音缺少这两个字段仍可读取。未完成的初译在 SRT / 文本导出中带 `[初译]` 标记。

HY-MT2 使用 PyTorch/Transformers，未引入 llama.cpp，也未升级 ASR 环境。1.8B 官方配置使用 `hunyuan_v1_dense`，标注 Transformers 4.57.6。
模型按用户选择在 CPU 或 CUDA 上加载，CUDA 支持时使用 BF16，否则 FP16；CPU 使用 FP32。两个模型共用 GPU 时仍需实际检查峰值显存和积压。
沿用官方 1.8B 推荐采样参数；单次译文限制 1024 token，输入限制 8192 token，超限明确报错并保留源文。

## 验证

自动测试覆盖中间修订不触发翻译、初译快照、最终请求替换、冻结上下文、草稿排除、缓存、过期结果拒绝、失败保留译文及旧录音兼容。重构实测见 [两阶段提交验证](testing/TWO_PHASE_TRANSLATION.md)。
真实模型快速检查：`.venv-wlk\Scripts\python.exe scripts/check_hy_translation.py --model models/Hy-MT2-1.8B --device cuda`。
它仅使用人工歧义句，不录音、不联网下载；结果保存在 `.work/hy-translation-smoke.json`。这种检查不等于完整翻译质量评测。

官方参考：[Hy-MT2 指令和推理说明](https://github.com/Tencent-Hunyuan/Hy-MT2/blob/main/README_CN.md)、[1.8B 模型](https://huggingface.co/tencent/Hy-MT2-1.8B)。

本机真实验证（RTX 5070 Ti，CUDA）：同一随机种子下，`The crane was moving slowly.` 在无上下文时译为“起重机移动得很慢。”，加入湿地观鸟及展翅飞走的背景后译为“鹤移动得很慢。”；`He was at the bank.` 从“他在银行里。”变为“他在岸边。”（后文是河边钓鱼）。四次生成分别约 0.672 / 0.313 / 0.218 / 0.172 秒，不含模型加载，不代表持续录音的端到端延迟。
权重已下载在 `models/Hy-MT2-1.8B`，选择内置模型名会复用该目录，不重复下载。下载规则包含必需的 `chat_template.jinja`；适配器去掉通用分词器生成的 `token_type_ids`，仅解码新增译文 token。
