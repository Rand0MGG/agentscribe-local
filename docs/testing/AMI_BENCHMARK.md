# AMI 整场实时测试协议 v1

运行 `scripts/benchmark_ami.py` 即依次完成：核验原始音频和人工标注、冻结参考/配置、准备完整音频、1 倍速连续回放、正常停止并排空队列、评分。每次自动创建 `.work/ami/ES2004a/日期时间/`，失败和中断会保留证据但不出分；旧结果不会覆盖。

## 输入与运行

- 固定官方 ES2004a Mix-Headset：17 分 29.355 秒，四人混合耳麦，非远场录音。音频和 AMI public manual 1.6.2 原始压缩包的 SHA256 固定在导入器；直接读压缩包中的四份 words XML 和四份 segments XML，不读可编辑的阅读版文本。归档 README 内部写着 1.7，版本身份以实际下载的 1.6.2 压缩包 URL 和 SHA256 为准。
- 默认 Qwen3-ASR-1.7B、fast 流式路径、英文、CUDA、draft 0.5s、endpoint 1.5s、SaT auto/CPU、无增强、关闭翻译。允许 `--settings` 传完整配置，但必须维持同一流式协议。冻结全部设置，不读取或修改桌面偏好。
- 仅解码和转换为 48k float32 输入；每 100ms 送入相应采样，不送未来音频。整段经过应用原有 Session、AudioJournal、worker、VAD 和字幕修订流程，不按 20/30 秒或参考句子独立调用模型，不重置会话上下文。文件输入替代声卡，不测量真实 WASAPI 驱动。
- 不加速：当前队列调度依赖实际时间和计算积压，快送音频会改变处理行为。运行约 18 分钟加模型准备/收尾，单独运行以减少其他 GPU 工作影响。
- 时间戳跳变大于一个源采样、首音频时间非零等情况直接拒绝；不静默压缩音频时间轴。输入最大迟到超过 250ms 会保留结果但拒绝本协议评分。此阈值是本地测试约定，非 AMI 官方阈值。
- 保存输入采样数、交付迟到 P50/P95/P99/max、实际墙钟耗时、依赖版本、代码快照/哈希、设置和全部字幕事件。

## 人工参考与评分

人工标注来源与本地重新人工核对是两回事。本协议接受固定官方人工档案作为数据集参考，且保留此来源声明；不会伪造逐句核对者或修改 CHAT 原有的人工认证门槛。

主指标是**按话轮开始时间排序的单流参考 WER**：话轮按开始时间、说话人 ID 排序，话轮内维持 XML 词序；假设取最终保留字幕按时间排列。WER=(替换+删除+插入)/参考词数，完整无输出按全漏词算，不把 1-WER 称为准确率。标准化复用 lexical-v1：NFKC、小写、标点边界、保留缩写撇号、数字不展开。

当前系统没有说话人分离输出。AMI 存在重叠讲话，所以该 WER **不是 cpWER、ORC-WER 或不受重叠排序影响的分数**，不能直接对比其他 AMI 排行榜。额外固定报告“按词时间排序”的参考 WER，作为排序敏感性检查；两者同时显示，不能择低。没有为了得到低分而去掉插话、重复或猜测说话人。

保留所有 `<w>` 词节点中的填充词和残词（本场36个），不采用完整词猜写；不把标点、笑声、咳嗽、disfmarker 等非词节点作为说出的词。音频中的这些声音仍全部送入模型。另报告固定填充词表排除后的辅助指标，参考与输出同时排除，不替代主指标。

本场有6个 gap 标记，正时长合计4.111秒；保留在审计中，不填入虚构文本，也不裁掉对应音频。这些区域没有可逐词比较的参考，所以邻近差异不一定是模型错误。词时间重叠、非词事件和原始属性全部保留用于复核；词时间来自对齐，不等同于人工逐词计时。评分不声称是严格无缺漏的整段金标准。

输出包括 `score/report.md`、`score/score.json`、`score/word-errors.csv`、`score/final-hypothesis.txt`、`score/final-captions.json`。差异 CSV 通过全局最短编辑对齐定位，重复词可能有多个等价定位；字幕时间仅供导航，不能视为真实逐词延迟。不同字幕中的真实重复文本不自动去重，撤回和旧版本字幕不重复计分。

## 命令

```powershell
Set-Location 'E:\codex_project\翻译'
.\.venv\Scripts\python.exe .\scripts\benchmark_ami.py
```

`--check-only` 验证原始数据和完整音频准备，不加载 ASR。
`--score-only <某次实验目录>` 复算完整运行，核验冻结文件和评分器版本，不重新识别。

依据：[AMI 官方人工标注下载](https://groups.inf.ed.ac.uk/ami/download/)、[AMI 转写规范](https://groups.inf.ed.ac.uk/ami/corpus/Guidelines/speech-transcription-manual.v1.2.pdf)、[MeetEval 对不同会议 WER 的定义与实现](https://github.com/fgnt/meeteval)。本协议未调用 MeetEval，不把自定义排序分数冒充其指标。
