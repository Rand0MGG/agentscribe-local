# 界面规范

目的：正文易读、常用操作直达，两端复用同一交互。本文规定界面目标，不代表所有边界已完成验收；实现缺口见 [计划](ROADMAP.md#实现缺口)。业务状态见 [spec](specs/README.md)，使用方法见 [指南](WORKSPACE.md)，实现位置见 [架构](ARCHITECTURE.md)。

## 布局与呈现

- 左侧录音库/导航，正文双语字幕；声音源、语言、音量及录音/回放共用悬浮小岛。设置/下载参数不占字幕正文，空状态只给必要的新建提示。
- 白色/深色仅改变颜色，保持同尺寸下的布局、间距、字重和圆角；复用 `ui_theme.py`。悬停轻微加深原背景，选中更明显；普通按钮不叠图形阴影效果，避免 painter 冲突。
- 主要文字稳定不透明；顶栏/侧栏共用缓存壁纸着色，后台生成，正文更新不重复模糊。材质不承诺真实透视或显示器 10-bit 色深。
- 主窗口可缩放，最小 640×480；小岛按可用宽度换行，设置/弹窗可滚动。长路径/设备名可省略但能查看全文；不缩小字体勉强塞入主要操作。
- Mac 保留原生框架、按钮与系统分屏，按 Qt 能力延伸背景及预留按钮/全屏安全区；Windows 保留原生缩放/Snap 适配。不要复制两套布局。

## 状态与操作

- 覆盖加载、空、失败、取消和完成；状态文案与实际结果一致，失败给出可执行的下一步，不能把检查失败、部分完成或未保存显示为成功。动画不改变业务状态或拖延保存。
- 原文显示“优化中/已定稿”，初译及过期译文明确标记。新增文字渐显不积压，修订立即替换；完整内容从开始就参与布局、复制、保存和翻译，减少动态效果时直接显示。
- 未开始时隐藏音量，不显示占位；聆听显示 RMS 音量，暂停归零，切源只接受当前代次。回放替换为播放/暂停、定位与时长，隐藏采集控件。
- 手动上翻暂停自动跟随，可返回最新/播放位置；查找只定位。关闭当前录音先完成业务收尾，不丢内容；完整规则引用录音 spec，不在此另设状态机。
- 模型下载入口少量明确选择，高级设置按需展开。任务卡保留进度和取消，未知总量不显示假百分比；下载完成不自动录音或宣称 GPU 已验收。
- 反馈为右上非模态提示，不抢焦点/改变正文高度。进度刷新不反复弹出或续时；弹窗收起不丢任务状态，失败和取消入口仍可找到。决策用对话框；Windows 更新仍可能显示原生 WinSparkle 窗口，不宣称全部自绘统一。
- 悬浮字幕原文/译文字号一致，背景透明度不影响文字；可拖动/缩放，控制栏隐藏保留空间，字幕更新不重置位置。重开校正到可用屏幕区域。

验收覆盖黑白主题、1280×840 及上述窄/竖窗口，中英混排、长名称、设置展开/到底、菜单与圆角裁剪、减少动态效果、连续追加/修订、悬浮位置保留与真实关闭。UI 测试拒绝绘制/资源销毁警告；设备、回听和模型另按 [TESTING](TESTING.md) 验收。
