# 界面规范

正文易读、常用操作直达，Windows/macOS 共用交互。业务约定见 [spec](specs/README.md)，操作见 [指南](WORKSPACE.md)，实现见 [架构](ARCHITECTURE.md)；实现与验收缺口见 [计划](ROADMAP.md)。

## 使用与约束等级

本文是产品 spec 的组成部分，也是 AgentScribe 视觉与交互设计的唯一正文，适用于主窗口、设置、模型管理、课程面板、菜单、通知和悬浮字幕。设计目标是安静、清晰、以双语阅读为中心的录音工作区。

- **统一规则**：后续新增或改造的界面必须遵守；不符合的旧实现按 ROADMAP 迁移，不因本文更新就宣称已完成。
- **参数基线**：下表明确标注的数值用于统一实现与比较。布局单位均为 Qt 逻辑像素，时间为毫秒；系统缩放由 Qt 处理，不手动重复乘缩放比例。
- **现有行为**：“录音与回放”“字幕与反馈”保留已经约定的产品行为。重构组件不得改变数据、权限、保存和取消语义。
- **待评估**：文末列出的体验变化不属于本轮统一规范的实施要求，不允许以“统一 UI”为由顺带加入。

优先级为用户当前明确要求、产品与数据约束、本文统一规则、页面局部设计、外部参考。遇到冲突先解决上层约束，不用特殊样式遮盖问题。

## Demo 一致性与优先复用

**UI Demo 是后续界面开发与验收的基准，不只是外观参考。** 新增和修改的页面、功能入口、控件及状态反馈，必须优先复用 Demo 已采用的共享实现，保持交互逻辑、风格和外观一致；不能只做相似截图，也不能另写一套看似相同的控件或状态逻辑。

| 基准 | 负责的契约 | 入口 |
| --- | --- | --- |
| 组件 Demo | 控件外观、输入响应、状态、主题与动效 | [独立 Qt 展示窗口](#独立-qt-展示窗口) · [preview_components.py](../scripts/preview_components.py) |
| 正式流程 Demo | 页面组合、任务入口、选择保持、进度、失败恢复与流程衔接 | [正式流程展示](#正式流程展示) · [preview_workflows.py](../scripts/preview_workflows.py) |

- **外观一致**：同角色使用同一主题、字号层级、颜色、尺寸、间距、圆角、阴影、图标与对齐；明暗主题、宽窄布局及所有适用状态都保持一致，页面不得用局部样式另造同类外观。
- **交互一致**：点击、悬停、按压、选中、禁用、键盘焦点、展开/关闭、滚动、输入校验、动效与减少动态效果遵循同一组件契约。加载、成功、失败、取消、重试和退出的可见状态与操作逻辑也须一致，不能只对齐正常状态。
- **实现复用**：从 Demo 定位其使用的主题、共享控件和正式业务组件，在正式页面直接复用；Demo 脚本负责场景装配和隔离夹具，生产代码不得依赖演示脚本或复制其模拟任务。业务资格与回执仍来自正式模块。
- **新增与修改同步**：先查组件及流程 Demo 中已有的对应场景；已有能力直接组合使用。确有缺口时扩展共享实现，并在同批改动中补齐或更新 Demo 场景、本文及相关回归，再用于正式页面。通用修正覆盖受影响的现有页面，不保留演示版与正式版两套实现。
- **差异处理**：同角色无需求依据的外观或交互差异视为缺陷。必要平台适配、可访问性或新的业务需求应说明差异及适用范围，并同步规范与 Demo；不能因某页实现方便而默认豁免。现有 Demo 的缺陷或未获确认的试验不能反过来覆盖产品与数据约束，应修正共同实现和场景。
- **验收一致**：在相同主题、逻辑尺寸和状态下比较 Demo 与正式页面的外观，并验证相同操作序列的结果、焦点、动效和恢复路径；共享代码或截图相似本身不等于流程通过。隔离夹具不证明真实音频、模型、网络或另一平台可用，证据边界沿用 [TESTING](TESTING.md)。

## 设计决定的归属

| 决定 | 唯一归属 | 页面如何使用 |
| --- | --- | --- |
| 颜色、字号角色、间距、圆角、层级与动效用途 | 本文定义语义；[ui_theme.py](../linguaflow/ui_theme.py) 统一提供实现值 | 按角色取值，不复制颜色常量或另建主题 |
| 按钮、选择器、菜单、弹窗的尺寸与状态 | 共享组件；优先复用 [ui_components.py](../linguaflow/ui_components.py)、[qt_controls.py](../linguaflow/qt_controls.py) | 选择用途、规格与状态，不在页面重新定义控件外观 |
| 字幕、录音小岛、回放、设置行等业务呈现 | 对应业务组件 | 传入真实状态和内容，不复制一份状态机 |
| 页面结构、主操作与窄布局 | 本文页面模板 | 组合现有组件，不另建同类页面规则 |
| 保存、模型、录音、云端许可等资格判断 | 对应业务模块与 spec | UI 呈现结果，不根据动画或按钮颜色推断成功 |
| 平台窗口、安全区和原生能力 | 现有平台适配层 | 共享内容与交互，保留必要系统差异 |

同一控件在两个页面需要相同修正时，修正共享组件。页面可设置内容布局、业务专有尺寸和可见性；通用颜色、焦点、圆角和状态样式不得逐页覆盖。特殊尺寸须说明用途、窄布局与验收方式，不为单处差异增加全局配置。

当前组件 Demo 的窗口按钮直接复用 `window_chrome.WindowButton`，不维护独立的绘制副本；字幕、录音树、录音控制区按各自组件组合，页面不复制其内部布局。

标准控件能否减少自定义实现、同时保持现有外观和交互，仍在讨论阶段，见 [ROADMAP 的 R27](ROADMAP.md#待评估的产品取舍)。具体技术路线、替换范围与实施顺序尚未确定，本规范不将候选方案作为已接受的实现要求。

实现迁移采用“替换并删除旧规则”，不长期保留新旧两套主题。明暗主题分别声明语义颜色；不再新增通过正则替换、亮度反转或页面补丁推导主题的路径。原有转换链已移除，appearance_style 从显式语义颜色生成统一样式。

## 视觉基础

### 颜色与表面

以下为沿用当前 `THEMES` 的起始基线，实施时从同一个主题对象读取；以后调色须同时检查两种主题及实际背景，正文不维护另一份运行时配置。

| 语义角色 / 当前键 | 浅色基线 | 深色基线 | 用途 |
| --- | --- | --- | --- |
| 正文表面 `surface` | `#ffffff` | `#191919` | 阅读区、纯色浮层 |
| 窗口材质底色 `glass` | `#f7f5f5` | `#272629` | 顶部与侧栏；不代表真实透视 |
| 控件表面 `control` | `#f5f5f6` | `#2b2b2e` | 输入与次级操作 |
| 主要文字 `text` | `#29292d` | `#ededf0` | 原文、名称、主要说明 |
| 辅助文字 `muted` | `#666670` | `#aaaab2` | 时间、提示、次要说明 |
| 译文 `translation` | `#515158` | `#c4c4cb` | 双语正文中的译文 |
| 边界 `border` | `#e7e5e7` | `#353538` | 必要的分隔和控件边界 |
| 主操作 `primary` / `primary_text` | `#29292d` / `#ffffff` | `#ededf0` / `#242428` | 当前任务的主要操作 |
| 错误 `error` | `#a62d27` | `#efa4a4` | 错误说明与恢复提示 |
| 警告 `warning` | `#a16b25` | `#d7ac6a` | 需要注意但未失败的状态 |

- 悬停、按压、选中、禁用、焦点和播放高亮使用主题中的对应角色，不用某个页面的临时灰色代替。ARGB 覆盖色必须在实际表面上合成后检查。
- 正文与普通操作保持中性色；错误、警告颜色表达状态，不装饰无关内容。颜色须与文字、图标或状态标签共同表达含义。
- 普通内容分组优先使用留白和分隔线；只在确有独立操作或边界时加容器，不层层套卡片。输入框保留可辨识边界。
- 阴影只用于窗口外壳及有浮起关系的小岛、菜单、提示与音量浮层，复用共享绘制。普通按钮、标题、字幕悬停不新增阴影。
- 正文和可操作文字的对比度目标为 4.5:1，关键控件轮廓及状态标记目标为 3:1；禁用样式仍须可辨认。此为后续验收目标，不表示现有所有状态已测量通过。

### 排版与尺度

使用系统字体与中文回退，沿用现有平台字体适配，不引入专有字体。正文保持常规字重；强调通过层级与有限字重表达，不把所有标签加粗。

| 角色 | 统一基线 | 说明 |
| --- | --- | --- |
| 工作区标题 | 16 / 400 | 录音标题，长标题省略并可查看全文 |
| 工作区文字操作 | 15 / 400 | 标题栏常用操作 |
| 导航与表单标签 | 13；标签按需 500 | 侧栏入口一致，不按页面随意变化 |
| 辅助说明 | 12；紧凑时间标记可用 11 | 不承担主要正文或唯一错误说明 |
| 设置页标题 | 26 / 600 | 沿用现有标题基线，不混用上一轮建议的候选值 |
| 对话框标题 | 21 / 600 | 对话框与设置页层级不同 |
| 字幕正文 | 沿用用户字幕字号设置 | 原文、译文的层次由颜色与间距表达；悬浮原译文字号相同 |
| 通用间距 | 4、8、12、16、24、32 | 新增布局从这组取值；字号基线、平台安全区与业务专有留白可例外 |
| 普通文字按钮、图标按钮 | 高 32；图标按钮命中区至少 32×32 | 规范化目标；图标视觉尺寸与点击面积分开 |
| 主要录音／播放控件 | 40×40 | 沿用现有传输控件规格 |
| 侧栏导航 / 正文栏 / 拖动区 | 38 / 40 / 36 | 系统安全区可提高下限 |
| 通用控件 / 菜单 / 主表面圆角 | 9 / 12 / 18 | 依次对应控件、浮层与工作区/小岛，不全部使用同一圆角 |

主按钮允许内容增加宽度，不通过缩小文字硬塞。多行正文由 Qt 文本布局测量，不能用固定单行高度截断中文；原译文组的段间距必须大于同组内部间距。图标沿用现有绘制体系，同角色保持笔画、视觉尺寸和对齐；可见图形须在命中区内部。

## 页面模板与布局契约

### 共用工作区

窗口分为系统拖动/控制区、左侧导航、右侧主内容；正文主表面贴合右侧与底部。标题栏只呈现当前对象名称和相关操作；全局设置留在全局入口。阅读区保持单一主要滚动方向，不让父子滚动区争夺同一正文。

| 模板 | 固定结构 | 主要操作与内容 |
| --- | --- | --- |
| 待录音 | 录音库 + 可编辑标题 + 居中摘要 + 单行小岛 | 来源、语言、文件夹可核对；开始是唯一强调操作 |
| 聆听 / 暂停 / 收尾 | 同一工作区 + 字幕流 + 稳定的小岛 | 状态、实际采集时间、音量、暂停/继续、结束；收尾按真实资格禁用操作 |
| 回听 | 同一工作区 + 双语字幕 + 回放小岛 | 播放、进度、时间、独立音量；搜索定位与播放分开 |
| 设置 | 分类导航 + 标题/说明 + 分组设置行 | 每行说明一个设置；高级参数按需展开；页内保留所属任务进度和取消 |
| 资料与笔记 | 课程上下文 + 任务分区 + 主阅读/编辑区 + 所属操作 | 本地原页、云端阅读、术语审核、笔记各自标明状态和许可 |
| 短任务对话框 | 标题 + 必要说明 + 内容 + 操作区 | 改名、确认、恢复等；不将长期阅读或任务进度强塞进确认框 |
| 悬浮字幕 | 原文/译文 + 可隐藏控件 | 内容优先；保留独立位置、尺寸、背景透明度 |

设置中的常规、聆听、模型、字幕与运行环境使用同一标题、分组、说明与操作层级；不能因为嵌入旧管理面板而获得另一套规则。课程面板可以保留独立窗口，其基础组件仍须统一；是否改为主工作区辅助栏另行评估。

### 窄布局与内容宽度

- 验收尺寸以逻辑尺寸为准：主窗口最低 640×480，基准 1280×840，补充 900×650 与 700×960。辅助窗口须受可用屏幕约束，内容超出时可滚动访问主要操作。
- 主字幕列沿用现有约 900 的内容尺度，设置沿用约 850；宽窗口增加外侧留白，不无限拉长文字。实际布局由字体、内容及现有容器测量，不把数值当作裁切宽度。
- 控件依据所在容器的可用宽度适配，不能仅依据整个屏幕宽度判断。窄标题栏先省略标题，再收纳次要操作；停止、取消、保存恢复等关键入口不得消失。
- 设置行按“文字区最小可读宽度 + 控件自然宽度 + 间距”判断是否能并排；不足时改为说明在上、控件在下。不将中文挤成单字列，不缩小正文。
- 弹层以锚点定位并夹在可用屏幕内，高度不足时列表内部滚动；长名称提供全文提示。选择值、禁用原因和关闭入口仍可访问。
- 自动折叠主侧栏、引入第三栏等结构变化暂不纳入统一要求；现阶段保留已有导航能力，按上述规则保证内容可用。

## 组件契约

| 组件 | 统一规则 | 必须覆盖的状态 |
| --- | --- | --- |
| 按钮 | 主操作使用实色，次操作使用控件表面，工具操作使用安静样式；破坏操作明确名称与后果；同一任务区最多一个强调主操作 | 正常、悬停、按压、禁用、忙碌；可切换按钮另有选中态 |
| 图标按钮 | 有工具提示与可访问名称；命中区不依赖图标笔画；危险操作不靠图标猜测 | 与普通按钮一致，选中态不等同悬停态 |
| 选择器 | 复用 ChoiceBox 与浮层表面；省略只改变显示，不改变实际值；空列表仍呈现原因及适用的刷新入口 | 未选择、已选、空、禁用、长文本、展开与关闭 |
| 文本输入 | 说明、值和校验错误有明确关联；失败保留输入；中文输入法确认不能误触提交或关闭 | 编辑、无效、禁用、提交中、失败恢复 |
| 开关 | 标签表达开关控制的事项；影响范围与生效时机写清；不把开关当一次性执行按钮 | 开/关、禁用、无法变更时保留真实状态 |
| 菜单 / 提示 | 一层纯色表面与共享阴影；提示不遮挡持续操作、不抢焦点；操作菜单保留禁用和关闭行为 | 长名称、禁用、屏幕边缘、主题切换 |
| 对话框 | 复用 SurfaceDialog；只有需要即时决定或输入时阻断；取消不提交修改 | 正常、校验失败、执行中、关闭/取消 |
| 进度与通知 | 所属页面有持续状态；全局通知只作提示；收起不等于取消；失败有原因和可执行恢复 | 已知/未知总量、取消中、完成、失败、已收起 |
| 字幕段 | 原译文成组；状态明确；修订原位更新；播放高亮与搜索目标不混淆 | 草稿、初译、定稿、过期译文、播放句、搜索命中 |

不要为所有组件强加没有意义的状态，例如提示气泡没有“保存成功态”。同一交互只由一个组件负责反馈，不同时叠加页面动画、组件动画和系统外框。

### 所有组件的共同契约

- 触发：禁用状态不发出业务操作；点击反馈即时，耗时结果由对应任务回执决定。按下后移出再释放不得误触；忙碌期间不重复提交同一任务。
- 状态：普通、悬停、按压、选中、焦点、禁用分别表达。隐藏组件不占用不必要空间；显示/收起不能清空用户值。只有当前有效任务可以更新状态。
- 中断：用户输入优先；动画从当前位置反向或换目标，不重播队列；减少动态效果立即结束装饰动画。窗口关闭释放自有计时器、浮层和任务，不能影响其他应用会话。
- 键盘：普通输入与选择器沿用 Qt 基础行为；弹层只响应自身作用域内的按键。输入法候选确认、Escape 先交给输入法，不得穿透到提交/关闭。没有为录音控制条注册新快捷键的授权。
- 焦点：可聚焦触发器打开模态后，焦点进入首个可操作控件；关闭后归还仍有效的触发器。非模态通知不夺焦点。原为 NoFocus 的控制条不因展示原型改变正式策略。
- 几何：所有弹层受可用屏幕边界约束；超长内容可滚动，取消和主要动作可达。平台安全区优先于样式参数。

## 动效与滚动契约

动效用于解释状态和空间变化，不模拟处理进度。动画可中断，新目标从当前位置接续；内容更新替换目标，不排队重播。隐藏、关闭和销毁时停止无用动画；减少动态效果时直接到达目标，业务流程不变。

| 场景 | 参数基线 / 当前策略 | 共同要求 |
| --- | --- | --- |
| 按压 | 即时反馈 | 不等待过渡才执行操作，不增加弹跳形变 |
| 切页 / 开关 | 150ms | 不移动焦点来配合装饰效果 |
| 对话框淡入 | 140ms，平台支持时使用 | 透明度能力不足不影响可操作性 |
| 小岛尺寸 / 音量展开 | 280ms / 200ms | 可反向和中断，不挤压正在阅读的正文布局 |
| 新文字显现 | 当前 80–320ms 上限策略 | 完整文字从首帧参与布局、复制、保存；修订立即替换 |
| 自动字幕跟随 | 当前时间常数 85ms，详见 CaptionScrollArea | 按实际时间计算，目标变化不重启动画积压 |
| 用户滚轮 / 触控板 | 使用 Qt 与系统输入语义 | 不另加固定滚动速度，不破坏像素增量、方向和惯性 |

精确现行算法见 [caption_view.py](../linguaflow/caption_view.py)，其他动效见共享组件与 [playback_controls.py](../linguaflow/playback_controls.py)。参数集中化尚待实施；调整参数须对照连续追加、修订和手动打断场景，不能只凭孤立动图决定。

滚动控制权按以下规则判定：

1. 实时跟随：仅在跟随状态追随最新内容；用户真正滚动立即打断，滚动手势的空开始/结束事件不误打断。
2. 手动阅读：保持当前阅读锚点，前文修订不能把视口推走；不得等待固定冷却时间后擅自恢复跟随。
3. 返回最新：用户触发返回入口，或按既有底部判定恢复；按钮位置避开小岛。
4. 回放跟随：目标为播放句，排除小岛遮挡区域；沿用下文关于播放句可见性与阅读偏移的规则。
5. 搜索定位：只定位并保持阅读，不恢复实时跟随，也不启动音频播放。

150ms 的外部滚动冷却示例不是滚动速度；外部容差、弹簧和渐隐参数不能直接替代本项目已定义的阅读行为。

## 布局与呈现

- 左侧录音库，右侧纯色正文；顶部与侧栏共用背景。正文填充与边框共用圆角轮廓，右侧、底部贴合窗口，不留半透明间隙或露出方形底板；录音和设置页一致。
- 明暗主题共用尺寸、字重和间距，复用现有组件与图标。品牌与正文标题视觉对齐；导航图标、文字列与根文件夹对齐，笔画完整位于悬停背景内，不靠负坐标补偿。
- 文件夹行右侧只保留更多菜单，不显示新录音加号，也不保留其点击热区；“文件夹”标题旁的加号仍用于新建文件夹。
- 标题使用常规字重，悬停不加底色或阴影；长标题省略并提供全文提示。窄窗口将课程 Beta 入口收入“更多”，优先保留标题与主要操作。
- 普通按钮参考本机 Codex `26.1013.4894.0` 的实际聊天按钮角色：次要按钮用文字色 5% 叠底、悬浮/按下 10%，工具按钮悬浮用浅色 8% / 深色 12% 叠色；按下沿用悬浮层，不重复加深。主按钮悬浮用 80% 前景色。按钮尺寸不随状态变动，鼠标操作不留焦点圈；键盘焦点保持可见。不叠阴影；小岛、音量浮层与菜单共用轻阴影，阴影连续衔接边缘，不留透明断层。提示气泡匹配主题、限制宽度、保持在屏幕内，离开或操作即收起。
- 所有选项列表、操作菜单及语言弹层沿用小岛来源菜单的纯色表面、圆角和轻阴影；只绘制一层菜单表面，外围为透明留白，不额外叠加玻璃底板或系统外框。明暗主题一致，保留选择、禁用、滚动与关闭行为。
- 正文仅在顶部渐隐；小岛周围和下方文字保持可见，但小岛以下不计入跟随判定的可读区域。渐隐层不拦截鼠标。背景材质缓存并在后台生成，不随字幕重复模糊，不承诺真实透视或 10-bit 色深。
- 最小窗口 640×480；窄窗口、设置和弹层保持可操作，必要时滚动，长设备名可换行或省略并查看全文，不缩小主要文字硬塞内容。Mac 保留原生按钮、分屏与安全区，Windows 保留窗口按钮、缩放与 Snap；顶部不重复品牌。
- 课程面板沿用明暗主题；原页切页从顶部开始，同页缩放保留阅读位置，本地准备与云端阅读分别操作。

当前尺度由组件与主题维护：侧栏导航高 38px，透明拖动区 36px，正文栏 40px；标题 16px、操作 15px，侧栏入口（含新录音）统一沿用主题 13px 字号，导航笔画内缩 12px。平台安全区可提高下限。

## 录音与回放

- “新录音”直接进入待录音页，不弹创建表单。来源、语言、文件夹使用图标入口；摘要全部逐行居中于纯色面板，随缩放和侧栏调整定位。标题可原位改名，按下开始前不创建文件，不提供关闭录音按钮。
- 聆听中可改当前名称、管理其他录音；当前录音及祖先目录保留移动/删除保护，切换仍须先停止并保存。已结束的空录音显示“无内容”，活动会话显示聆听、暂停或故障状态。数据规则见 [录音规范](specs/recording.md)。
- 待录音小岛单行，不预留隐藏控件空间；录音时上行呈现状态、实际采集时长与音量，下行呈现来源、语言、暂停/继续和结束。当前录音宽 288px，上下留白平衡；尺寸切换采用 280ms 可中断过渡，不被隐藏页面撑高。
- 音量按输入呈现，暂停归零；计时按已接收 PCM，不计加载或暂停时间。来源列表底部提供刷新，空设备列表仍可打开；省略不改变选择，切源遵守会话代次。
- 录音反馈以采集事实为主：小岛以普通字重稳定显示“录音中”和计时，模型加载不占用小岛位置，也不影响输入音量说明和可视化。加载期间右上角显示单条“正在加载模型”进度通知，就绪后收起；正文简短确认“录音已开始”，模型就绪且暂无首句时显示“正在聆听”。就绪和追赶不另弹通知，不展示积压处理说明，也不让录音状态反复切换；无声音、暂停、失败与停止保留明确反馈。悬浮字幕无内容时沿用同一状态文案。
- 回放的播放键、长进度条与时间同排。独立音量圆钮与小岛等高，点击向上展开并显示百分比，不挤短进度；支持最高 300%，格式限制须说明，数据与增益边界见录音规范。
- 滑块均支持点击定位和拖动，拖动不被旧回执覆盖。回听仅在实际字幕文字范围内短单击定位，空白、拖选、长按、双击及录音中不触发；可点文字保留手形光标和即时按压反馈，鼠标悬停不改变句子背景，播放句仅背景高亮，无左侧竖线。
- 手动滚动打断跟随；返回箭头指向播放句，句子可见时隐藏。用户将当前句滚入视野后，下一句沿用其窗口偏移平滑跟随；远离时保持阅读位置。查找只定位，新目标替换进行中的滚动，不堆积动画。长录音提供更早/较新字幕分页入口，搜索及回听可跨页定位，返回箭头也可返回页外的最新字幕或播放句；分页不丢弃完整文字。

## 字幕与反馈

- 草稿、初译、定稿及过期译文明确区分。未分句原文立即预览，在原区域替代可修订尾部；正式字幕原位接续，不重复、伪定稿或提前触发翻译，悬浮字幕同步有效修订。
- 新增文字可渐显，修订立即替换；完整文字从开始就参与布局、复制与保存。命中区域按内容/字体/尺寸缓存，内容不变时避免重复排版。“减少动态效果”直接切换，保留跟随与业务行为。
- 悬浮字幕原文/译文字号一致，透明度只影响背景。隐藏控制栏与缩放柄后释放正文空间，保持位置尺寸；可拖动缩放，重开校正到可用屏幕，内容更新不重置位置。
- 状态覆盖加载、空、失败、取消和完成。成功保存静默更新，新录音页收起旧成功提示；失败、未完整结束与进行中任务保留。右上通知不抢焦点、不改变正文高度，进行中进度不按时间自动消失，完成后结束进度；用户收起后，阶段更新不重复弹出。取消和错误入口始终可找；迁移与模型检查收起后仍可从“更多操作”取消，模型下载可回模型管理取消。保存、识别及课程错误不自动过期；保存错误收起后仍可从“更多操作”重试或备份全部文字。操作失败直接显示原因，诊断记录保留完整错误，不要求用户先打开诊断才能知道如何修正。通知不提供“详情”展开入口，不自动切页或展开正文诊断区，保留既有诊断记录。
- 模型下载使用少量明确选择，高级参数按需展开；模型准备的详细进度、取消与失败重试在模型管理页显示；环境修复在运行环境页顶部显示同一任务卡；其他页面使用一次性进度通知，收起不取消、不因进度或阶段更新反复弹出。未知总量不编造百分比，完成不自动录音。自绘控件明确约束高度与边框，菜单独立布局；Windows 原生更新窗口不强行统一外观。
- 不注册应用快捷键或控制条专用焦点/按键行为；文本编辑、复制粘贴及系统控件沿用基础行为。动画不得改变业务状态或延迟保存。
