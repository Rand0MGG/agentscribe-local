# 模型与运行环境

目的：一次明确准备后可靠本地运行，避免隐式下载、错误设备和环境互相污染。

## 选择与准备

- 引擎、模型、设备分别表达；格式可导入不等于任意模型可用。下载目录给出少量明确选择，高级参数按需展开；浏览/单独下载不改选择，明确应用才保存下次会话配置。
- 平台推荐由 `model_options.py` 统一：Windows Qwen 1.7B/PyTorch，Apple Silicon Qwen 1.7B/MLX 4-bit，翻译推荐 HY 1.8B Q4_K_M。MLX 8-bit 在目录内仍须实机验收；不因目录更新替换旧自选模型或有效设备。
- 准备接收独立选择与范围快照：只维护所需识别、分句或翻译组件；关闭翻译不要求翻译文件。环境修复不下载权重，模型准备不检查无关后端；明确的推荐组合操作可准备完整所需组合。
- 缺少/未指定所需模型时才显示可关闭引导，普通后台检查不自动下载或反复弹窗；检查失败不能冒充模型缺失。任务切页后继续，进度、错误与取消入口仍可找到。
- 权重缺分片、空文件或损坏索引不能就绪。固定组件与内置 GGUF 核对版本/摘要；Whisper 下载核对上游摘要后原子替换。取消保留有效旧文件和可续传部分。
- 自选 GGUF Hub 引用保持原样，准备只下载指定文件；格式检查不证明架构/模板兼容。运行只解析本地完整缓存，不在开始聆听时下载大文件或偷偷联网补权重。

## 环境与设备

- 桌面、WLK、MLX 分离；MLX 子进程接收 PCM、返回字符串，共用字幕和翻译规则。运行路径统一经 `runtime_paths.py`，兼容旧 venv 和模型缓存。
- 先校验平台、架构、驱动和所选设备。GPU 目标需实际推理和设备确认，失败明确报错，不静默 CPU 回退；显式 CPU 对照不等于 GPU 验收。当前 Windows 整套推理环境安装有 NVIDIA 门槛，不能把翻译支持 CPU/Vulkan 误写成任意 CPU 电脑可安装整套应用。
- 新环境在最终稳定路径创建，锁内安装和校验后原子切换记录，不移动 venv、不覆盖旧环境；失败/取消保留旧可用环境。安装态基础 Python 位于稳定用户目录，不依赖将被替换的程序包或另一套系统 Python。
- 按平台、ABI、依赖和基础解释器选择兼容环境。清理只处理归属摘要完整、内容未变、无进程使用且无当前/回退引用的管理槽位；未知、改动、映射、失败材料、旧源码 venv、共享基础 Python、模型和用户数据保留。
- ASR 与 SaT 共用并行启动和取消管理，全部成功后才建立 VAD/流式任务和采集。失败或取消关闭已登记及迟到资源，回收加载任务；VAD 不受加载期间全局半精度影响。
- SaT 固定 CPU，随 ASR 准备；ORT 优化缓存按运行库/架构/权重隔离，完成后发布。开录只读兼容缓存，无缓存沿用原始 ONNX；实际载入损坏要报错，不吞异常。
- llama.cpp 服务只绑定本机回环、每会话认证、忽略代理；GPU 选择确认全部层，CPU 显式关闭 GPU 层，关闭历史请求主机缓存以控制保留量。取消、正常结束和父进程异常退出都回收自有服务；不承诺关闭缓存必然改善全部性能。

## 验收

覆盖两端选择往返、旧配置、关闭翻译、单独准备、自定义路径/Hub 引用、断网缓存、取消中/加载中资源、损坏权重、环境事务/回退/安全清理。真实模型验收记录设备、完整输出、延迟及资源；模型目录、下载完成、文件存在或 GPU 可用都不足以宣称支持。
