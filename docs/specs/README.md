# 产品约定

AgentScribe 帮助外语课堂、讲座和讨论的参与者实时阅读原文/译文，并在课后回听、查找和导出。首先保证录音和文字可靠，再以可验证的质量与成本改进体验。

## 长期约束

- 核心识别与翻译在本机运行，准备后可断网使用；联网选择由用户决定。课程助手可选、默认关闭，云端用途单独授权，不上传音频，不影响本地字幕与保存。
- 原始录音、识别原文、模型解读、译文与个人笔记分别表达。推测不能冒充原话，初译不能冒充最终译文，未保存不能冒充保存成功。
- 修订、取消、失败、重开和退出仍要保护已获得结果；迟到任务不能覆盖新状态。用户数据和旧格式兼容优先于目录整齐或实现省事。
- Windows/macOS 共用产品行为；系统接口与模型协议可不同。不为平台维护两套业务，不静默换模型、设备或音频来源。
- 默认流程简单，状态符合实际；不以更多设置换取内部实现方便。算法效率、延迟和准确性一起评估，不承诺所有模型、语言和设备都已验收。

## 如何使用本规范

- 正文描述已接受的目标行为，不表示每项已实现或已验收。确认合理但尚未满足的要求在 [实现缺口](../ROADMAP.md#实现缺口) 跟踪；证据不足的方案先标待评估。
- “当前策略”说明现有算法或适配选择；精确阈值、预算、型号和版本由所链接的代码或锁维护，不因写入文档成为永久约束。改变策略要比较质量、延迟、资源与兼容影响，不能借整理文档改变默认行为。
- 行为变化同步更新对应规范和验收；实现边界见 [架构](../ARCHITECTURE.md)，操作见 [指南](../WORKSPACE.md)，验收方法见 [测试规范](../TESTING.md)，实际证据见 [验证索引](../VALIDATION.md)。代码存在、测试通过和安装包可用是不同状态。
