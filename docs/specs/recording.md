# 录音与数据

目的：从用户选择的声音获得可回顾的录音、字幕和译文。文件输入可验证推理，不能替代真实设备验收。

## 会话与输入

- 新建录音先确认名称和文件夹；取消不创建文件。模型/分句组件全部就绪后才开采集，加载中可取消。
- 空闲→启动→聆听；聆听可暂停、切源或停止。暂停/恢复/切换/收尾的过渡期间拒绝重复动作，停止后的 ready/status 不得恢复聆听。模型与推理配置使用启动快照；采集来源可按下述切换规则更新，独立按代次管理。
- 暂停确认前释放旧设备，拒绝迟到块；已接受音频、字幕和翻译继续处理。恢复沿用同一录音、模型和采样时钟，暂停墙钟时间不计入音频/字幕。
- 聆听时可切来源；暂停时可选择，继续后才打开。先释放旧设备，再接最新选择，以代次拒绝旧块和旧切换确认；失败保留现有录音并明确报错，不自动换麦克风。
- 两端支持原生麦克风与系统声音。Mac 刷新来源不请求屏幕录制权限或查询显示内容；采集只传声音，不保存屏幕图像。BlackHole 保留为普通输入兼容，无需安装它使用原生电脑声音。
- 音频处理只改变识别输入，磁盘录音保存原始采集 PCM；准备或优化不得擅自改变用户选择的声音来源。

## 保存、文件库与退出

- 字幕快照在后台串行、原子写入；只有录音身份、视图、版本及完成状态均匹配的成功回执才能清除未保存状态。旧回执不能覆盖新修改。
- 正常停止在有界期限内排空已接受音频，允许仍有效的字幕/翻译完成并保存；停止采集不等于取消收尾。取消、超时或会话/请求归属失效后拒绝迟到发布；超时或失败保留已获得结果并标记未完整结束，重复停止不能延长收尾期限。
- 关闭录音、导航、库操作、更新安装及退出，按操作范围等待保存和自有资源释放，期间 UI 保持响应。保存失败保留视图、恢复/导出入口和锁；不能提前销毁保存线程、绘制任务或子进程。
- 默认库位于系统用户数据目录，已有自选位置和非空旧库优先。重名创建/移动加序号，重命名冲突拒绝；校验保留名、目录归属、映射及文件锁，不覆盖另一会话或用户文件。
- 删除先进入同库垃圾桶；恢复不覆盖同名文件，永久删除须确认。兼容旧 `.最近删除`；不搬移旧数据，不覆盖用户自建同名目录。
- 改保存位置由用户明确发起：空目标、复制与校验、切换配置、仅清理未变化原件；失败/取消保留原件，重试识别已复制事务。旧 `library.json` 迁移保留原件，不能重复导入。
- 回听不启动模型或采集。按已有段落时间定位/高亮，查找只定位；时间属于估计，不承诺词级对齐。
- 普通导出 SRT/TXT/Markdown 只包含定稿原文与已有译文，未完成译文保留初译标记；后台冻结快照，失败保留已有目标文件，退出等待导出完成。
- 故障恢复与普通导出区分：保存失败时应提供能保留已获得文字的恢复备份，包括只有草稿的情况，并明确标识草稿/未完成状态；不能因不符合普通导出条件而丢弃恢复内容。此恢复要求及保存失败时的锁保护缺口见 [实现缺口](../ROADMAP.md#实现缺口)。

## 当前策略与实现定位

当前识别输入采用轻量增益/峰值保护，配置见 [`audio_processing/config.py`](../../linguaflow/audio_processing/config.py)；不恢复已退休的增强预设或自动下载增强模型。平台音频接口、采集代次和保存服务职责见 [架构](../ARCHITECTURE.md)。

## 验收

覆盖加载取消、暂停/恢复/切源的迟到块与设备失败、停止超时、保存失败/旧回执、仅草稿时的故障恢复、退出中任务仍在运行、旧数据和垃圾桶恢复、迁移取消/重试、中文/空格/深路径与真实映射。核对 PCM 次序和采样数、文字完整性、落盘内容和资源退出，不能只断言函数返回。

自动化入口及设备验收边界见 [TESTING](../TESTING.md)；实现与实机验证状态见 [ROADMAP](../ROADMAP.md)。
