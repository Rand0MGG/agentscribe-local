# 录音与数据

目的：从用户选择的声音获得可回顾的录音、字幕和译文。文件输入可验证推理，不能替代真实设备验收。

## 会话与输入

- 点击开始后，音频来源与保存位置通过基础检查即启动采集和 WAV 保存，不等待异步模型检查、运行环境导入或模型加载；模型文件校验与加载在会话后台进行。首次收到并保存音频块后才提示“已开始录音，正在加载识别模型”，设备尚未打开时只显示连接中，不能谎报已录音。显式模型检查仍可取消、不会自动下载；旧检查结果不得重复启动录音。

- 新建录音直接进入主窗口待录音工作区，沿用当前来源、语言、文件夹与建议名称；图标入口按需修改三项选择，顶部标题可原位改名，空白区显示当前选择。点击开始时才创建录音，重复新建不累积空草稿，不使用创建表单或独立创建弹窗。采集与识别/分句组件加载并行；加载期间已采集的音频按序进入磁盘缓冲，准备好后持续处理积压，不丢弃开头或按墙钟原速重放。推理输入队列有界，不能把整个积压搬入内存；处理速度不足时显示追赶状态，不保证任意设备都能实时。
- 明确选择的识别语言与翻译目标相同时，自动关闭翻译，并同步设置页和语言弹层；自动检测不视为同语言，简繁中文按不同目标处理。改回不同语言不会自行开启翻译；活动录音仍沿用启动时的设置，选择变化用于下一次聆听。
- 空闲→启动→聆听；聆听可暂停、切源或停止。暂停/恢复/切换/收尾的过渡期间拒绝重复动作，停止后的 ready/status 不得恢复聆听。模型与推理配置使用启动快照；采集来源可按下述切换规则更新，独立按代次管理。
- 暂停确认前释放旧设备，拒绝迟到块；已接受音频、字幕和翻译继续处理。恢复沿用同一录音、模型和采样时钟，暂停墙钟时间不计入音频/字幕。
- 暂停、停止和切源请求不等待磁盘写入；请求前已接受的音频块仍写完，再完成设备释放与状态确认。音频写入和暂停回调不得占用界面控制锁；切源交接时，暂停状态检查、等待登记与新采集段创建必须原子化，不能进入无法恢复的未登记等待。
- 音频磁盘缓冲按最多 4 MiB 分段，已消费的前段及时关闭回收；读空时截断并复用一个空尾段，避免按音频块频率创建文件。积压仍完整保留，累计采样时钟和暂停位置不因回收而重置。磁盘使用随未消费积压增长，不保证无限积压下空间充足。
- 不变文字的上下文复核与尾部分句复用有界缓存，不重复执行 SaT；依赖时间的就绪状态仍推进，原文变化仍重新分句。
- 聆听时可切来源；暂停时可选择，继续后才打开。先释放旧设备，再接最新选择，以代次拒绝旧块和旧切换确认；失败保留现有录音并明确报错，不自动换麦克风。
- 两端支持原生麦克风与系统声音。Mac 刷新来源不请求屏幕录制权限或查询显示内容；采集只传声音，不保存屏幕图像。BlackHole 保留为普通输入兼容，无需安装它使用原生电脑声音。
- 音频处理只改变识别输入，磁盘录音保存原始采集 PCM；准备或优化不得擅自改变用户选择的声音来源。

## 保存、文件库与退出

- 每次显式导出使用独立任务身份，按请求顺序执行；不同录音导出到同一路径时，不比较其字幕版本号或静默丢弃后一次请求，失败保留已有文件并报告。

- 崩溃预防与异常退出恢复分别验收；识别/翻译故障不得破坏已有录音。持久化不能只依赖正常退出，重启应识别并恢复未完成录音，保留原件并明确可恢复范围与尾部损失；不承诺未验证的零丢失。平台验收与剩余限制见 ROADMAP 的 R23。
- 原文预览到达即进入后台保存队列，不等待分句或停止；保存为可修订草稿并保留已有译文及其原文来源，分句成功后由正式字幕快照替换，不能重复显示或冒充定稿。新预览及预览完成均增加保存版本，旧回执不能清除新预览的未保存状态。
- 未完整结束录音的回放先检查录音锁；对本应用固定格式的 WAV，以物理完整采样校正只读流中的长度，保留原文件、不改写 PCM、不把不完整采样补成声音。恢复提示区分已读取内容与无法恢复的未落盘尾部；此校正仅用于应用内回放，外部工具直接读取原件仍可能受旧文件头限制。
- 字幕快照在后台串行、原子写入；只有录音身份、视图、版本及完成状态均匹配的成功回执才能清除未保存状态。旧回执不能覆盖新修改。
- 加载期间允许暂停、继续及切源；点击停止立即结束采集，已有音频在有界期限内等待加载并排空；尚未收到任何音频时可取消启动。加载失败、采集故障或收尾超时保留已保存 WAV 并标记未完整结束。
- 正常停止在有界期限内排空已接受音频，允许仍有效的字幕/翻译完成并保存；停止时等待正在执行的分句线程完成及发布后再作最终提交，取消整个会话则等待其退出但拒绝迟到发布；停止采集不等于取消收尾。取消、超时或会话/请求归属失效后拒绝迟到发布；超时或失败保留已获得结果并标记未完整结束，重复停止不能延长收尾期限。
- 关闭录音、导航、库操作、更新安装及退出，按操作范围等待保存和自有资源释放，期间 UI 保持响应。保存失败保留视图、恢复/导出入口和锁；不能提前销毁保存线程、绘制任务或子进程。
- 默认库位于系统用户数据目录，已有自选位置和非空旧库优先。重名创建/移动加序号，重命名冲突拒绝；校验保留名、目录归属、映射及文件锁，不覆盖另一会话或用户文件。
- 打开空库、点击“新录音”或打开保存文件夹选择时，若没有可用文件夹，自动创建并选中“我的录音”；此时不创建空录音。已有文件夹时直接复用，失效的旧选择回到可用文件夹；创建失败提示原因并保留当前视图。补建目录不得复用垃圾桶内文件夹的标识，恢复旧目录时仍保护同名内容。
- 文件夹/录音名称对话框使用明确保存或创建按钮，空白名称在字段旁提示并保留输入；Enter 不隐式提交，输入法合成时的 Escape 不关闭对话框，取消不写入。顶部原位改名沿用原有确认与取消行为。
- 聆听期间可重命名、移动或删除其他录音（仍检查文件锁）；当前录音及包含它的文件夹不可移动或删除，也不可切换当前工作区。当前录音可立即改名并保存；写入路径不变，停止后再同步目录名，失败保留原件与名称。
- 已结束的空录音显示“无内容”；聆听、暂停和来源故障分别显示真实状态，不因尚无字幕而误报为空录音。
- 删除先进入同库垃圾桶，恢复不覆盖同名文件；单项或全部永久删除均须确认。全部删除只处理确认前的列表，空列表禁用，失败或受引用保护的项目保留并提示。兼容旧 `.最近删除`，不覆盖用户自建目录。
- 改保存位置由用户明确发起：空目标、复制与校验、切换配置、仅清理未变化原件；失败/取消保留原件，重试识别已复制事务。旧 `library.json` 迁移保留原件，不能重复导入。
- 回听不启动模型或采集。按已有段落时间定位/高亮，查找只定位，结果明确显示总数、当前范围及空状态，所有匹配可分页访问；长录音以有限数量卡片分页，所有历史字幕均可浏览，搜索和回听定位须按需载入目标段落，手动翻阅不被新字幕抢走位置。时间属于估计，不承诺词级对齐。
- 回放音量仅控制当前应用输出，允许调至静音或放大至 300%，不修改系统设备音量或原始录音，不留下放大副本；超范围 PCM 峰值饱和处理。拖动进度时以用户位置为准；回听时可短单击实际字幕文字从该句开始播放，拖选/双击/空白不触发，录音中不触发。字幕平滑跟随可被手动滚动打断，用户可按指向当前播放句的箭头返回；若当前播放句被用户滚入可读区域，下一句保持该句的窗口内偏移继续跟随；减少动态效果时不等待动画。
- 普通导出 SRT/TXT/Markdown 只包含定稿原文与已有译文，未完成译文保留初译标记；后台冻结快照，失败保留已有目标文件，退出等待导出完成。导出与恢复备份在排队和写入期间保持进行中反馈，队列结束后移除；手动收起不取消任务，排队更新不重复弹出。
- 故障恢复与普通导出区分：保存失败时应提供能保留已获得文字的恢复备份，包括只有草稿的情况，并明确标识草稿/未完成状态；不能因不符合普通导出条件而丢弃恢复内容。“更多操作”始终提供重试保存和全部文字恢复备份；保存错误不自动过期。恢复备份是标明草稿、初译/过期译文和未完成状态的 TXT，包含即时原文预览，不包含音频，也不清除原录音的未保存状态。仅在原保存成功，或用户确认使用当前版本的成功备份关闭录音后释放锁；备份失败、取消、旧回执和新文字产生均不能解除保护。

## 本地故障诊断

- 桌面与推理进程默认持久化有大小轮转和时间保留策略的结构化元数据，以会话 ID 关联；用户可从更多操作打开目录。
- 识别记录窗口、实际新增音频、计算耗时、积压及切分/收尾原因；记录启动、停止、异常和保存结果。不得默认保存音频、原文、译文、凭据或私人路径。
- 诊断覆盖启动到退出的关键操作、程序状态与任务结果，并低频记录 CPU/GPU/RAM；明确系统/整卡与本程序范围及不可用值。重复进度需合并，不采集点击坐标、键盘正文或私人名称；异步写盘有界，不阻塞采集和 UI；每进程轮转预算约 32 MiB。资源采样不得要求提权或常驻辅助服务，输出只含必要数值与结果状态，不转存驱动原始输出。
- 日志失败不得破坏已有录音或阻止识别，需向用户报告；明确 Python 诊断与原生崩溃/断电证据的差别。保留与隐私策略见[使用指南](../WORKSPACE.md#诊断日志与问题反馈)，事件与延迟口径见[架构](../ARCHITECTURE.md#诊断日志)，日志不改变识别算法。

## 当前策略与实现定位

当前识别输入采用轻量增益/峰值保护，配置见 [`audio_processing/config.py`](../../linguaflow/audio_processing/config.py)；不恢复已退休的增强预设或自动下载增强模型。平台音频接口、采集代次和保存服务职责见 [架构](../ARCHITECTURE.md)。

## 验收

长录音优化必须保持原文修订、字幕 ID/时间、预览保存及分页定位一致。内容更新不重建无变化的字幕顺序；保存仍冻结提交时的数据，未变化的导出可保留原文件，缺失、部分写入或外部修改的导出须在下次成功保存时恢复。

录音库后台读取线程启动失败须通过已有错误反馈恢复空闲，保留原视图，允许重试和正常关闭；取消也不能使失败任务永久停留在忙碌状态。

异常退出使用隔离进程与合成 PCM，在录制、保存和收尾阶段强制终止后重新打开，核对音频采样数、文件可读性及文字恢复；Windows/Mac 分别验证。进程终止测试不等于断电耐久性验证。

覆盖空库与删空目录后的默认文件夹补建、失效目录选择、补建失败与旧目录恢复，以及加载取消、暂停/恢复/切源的迟到块与设备失败、停止超时、保存失败/旧回执、仅草稿时的故障恢复、退出中任务仍在运行、旧数据和垃圾桶恢复、迁移取消/重试、中文/空格/深路径与真实映射。核对 PCM 次序和采样数、文字完整性、落盘内容和资源退出，不能只断言函数返回。

自动化入口及设备验收边界见 [TESTING](../TESTING.md)；实现与实机验证状态见 [ROADMAP](../ROADMAP.md)。
