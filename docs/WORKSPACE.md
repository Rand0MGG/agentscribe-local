# 安装与使用指南

本文描述当前源码操作和已知限制；旧安装包以其发行说明为准。目标行为见 [spec](specs/README.md)，实现缺口见 [ROADMAP](ROADMAP.md#实现缺口)，平台证据见 [VALIDATION](VALIDATION.md)。核心识别与翻译在组件和模型准备后可断网使用，课程云任务需要网络及用途许可。

## 诊断日志与问题反馈

当前源码默认将结构化支持日志保存到 Windows `%LOCALAPPDATA%/AgentScribe/logs`、Mac `~/Library/Application Support/AgentScribe/logs`。工作区“更多操作 → 打开诊断日志文件夹”可直接打开；“诊断记录”仍是界面上的简短运行信息。报错后请保留同一时段的 desktop、worker 活跃文件及 `.gz` 历史归档，并说明软件版本、发生时间、操作和现象。

每个进程启动使用独立 `support-*.jsonl`，按 UTF-8 字节计算，每写满约 8 MiB 就切换新文件，将上一份无损压缩为 `.gz`；不拆分单条记录。取消每进程 32 MiB / 三份副本限制及 14 天过期规则。桌面与 worker 的**压缩历史共用 128 MiB**，按压缩后的实际大小计量，超限按原文件最后写入时间从旧到新删除，必要时删除多份，直到回到预算内。正在写的文件不计入历史预算；通常桌面、worker 各有一份，因此额外约占最多 16 MiB，压缩期间还需要临时空间。

压缩在日志后台线程完成，解压校验字节一致后才替换为正式归档并删除原件；正常退出时不足 8 MiB 的尾部也归档。启动、轮转与退出均维护预算，多进程通过目录锁协调；压缩历史即使属于仍运行的进程也可按年龄清理，活跃原始文件不动。旧轮转文件及崩溃遗留的原始文件在确认所属进程已退出后压缩；无法确认时保留，缺少进程检测组件的 worker 仍可归档自己的封存块并清理压缩历史。压缩或清理失败会提示并保留可恢复原件，未完成的 `.pending` 文件在后台重试或下次启动恢复；此时磁盘占用可能暂时超过目标。只处理应用自有命名的日志，跳过符号链接及无关文件。

采用 UTF-8 JSONL，每行包含 UTC、级别（INFO/ERROR）、单调时钟、进程/线程、会话 ID 和明确事件名；关键操作另有操作 ID。后台线程写盘，正常空闲时阻塞等待新记录；仅归档尚未完成时约每 5 秒重试，队列最多 1024 条，积压时省略记录并提示；正常退出最多等待写盘及归档 2 秒，不保证强制终止或断电最后几条可恢复。日志创建/写入失败会提示，不以诊断失败中断录音。

记录从进程启动、界面就绪到退出请求、等待任务结束与正常关闭；关键点击、页面切换、任务开始/取消/结果、录音状态和保存结果有记录。重复进度和普通自动保存最多每 5 秒一条，设置变化只记设置项、不记内容，不记录鼠标移动、音量电平或搜索输入。资源快照约每 10 秒一条，包含系统 CPU/RAM、本程序及仍存活子进程的 CPU/RAM；CPU 首样本未知，本程序 CPU 的 100% 代表一个逻辑核心，RAM 为 RSS 之和（共享页可能重复计数）。Windows NVIDIA 可用时记录整卡 GPU 利用率/显存及驱动提供的本程序显存；整卡数值包含其他程序，WDDM 缺失显存记为不可用。Mac 每次资源采样通过系统 `ioreg` 查询 IOAccelerator 的驱动统计，仅提取整卡利用率，不请求管理员权限、不安装辅助服务；查询限时 1.5 秒，失败或计数器缺失后间隔至少 60 秒再试。驱动未提供有效统计时明确标记不可用，不能保证所有 Mac/系统版本都提供该字段；这不是本程序独占利用率，也不是过去 10 秒的平均值。MLX 解码另记分配器内存，Apple 统一内存不冒充独立显存；原始注册表、终端输出和二进制数据不写日志。

默认不保存音频、识别全文、译文、设备名称、私人文件路径或模型请求。异常保留类型、errno 和调用堆栈的模块文件名/行号/函数，不保存异常原文、源码行和局部变量，避免第三方异常带出用户内容。Python 异常、保存失败和推理任务错误有记录；强制终止、原生驱动崩溃、断电不保证有终止事件，也不等于完整 native crash dump。既有显式回放诊断可记录原文，分享前须另行检查。

开发排查所需的事件与延迟口径见[架构：诊断日志](ARCHITECTURE.md#诊断日志)，已完成的验证及限制见 [VALIDATION](VALIDATION.md)。

## 安装与首次准备

### Mac 安装包

从 [v0.11.0 发行页](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.11.0) 下载 DMG，拖入 Applications。支持原生 Apple Silicon/macOS 15+，不支持 Intel/Rosetta；包内有桌面依赖，无需自行安装桌面 Python。当前包未 Developer ID 签名/公证，系统拦截时按发行说明操作，不全局关闭安全保护。

打开后在设置准备运行组件与模型，首次需要网络和磁盘空间。`0.12.1` 正在准备 Mac 安装包，新增交互以对应包的发行说明为准。

### Windows 安装包

从 [v0.11.0 发行页](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.11.0) 下载 x64 `.exe`，核对同页 SHA256 后安装；包内有桌面运行依赖，模型与推理组件仍需首次准备。此为未做 Authenticode 签名的预览包，要求兼容 NVIDIA GPU/驱动；真实录音、GPU 联动及旧版升级尚未验收，不代表当前源码全部功能。

### Windows 源码安装

下载 [Windows 分支](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/windows.zip)，安装 Python 3.12 和 Node.js（当前 CI 使用 24），在项目目录执行：

```powershell
py -3.12 -m linguaflow.hardware
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe scripts\install_runtime.py
Push-Location desktop
npm ci
npx install-electron --no
npm run build
Pop-Location
.venv\Scripts\python.exe -m linguaflow
```

本指南使用 Python 3.12，支持范围以 [pyproject.toml](../pyproject.toml) 为准。完整推理环境要求 Windows x64 和兼容的 NVIDIA GPU/驱动；最低计算能力与驱动要求由 [硬件检查](../linguaflow/hardware.py) 维护，以上首条命令会给出检查结果。检查失败先解决提示，不继续安装或回退 CPU。之后可用 `run-windows.cmd`；无需 WSL 或手动启动服务。拉取涉及前端的源码更新后，重新执行上面的 `desktop` 准备与构建步骤，避免继续加载旧界面。

### macOS 源码安装

下载 [Mac 分支](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/mac.zip)，在原生 Apple Silicon 项目目录执行：

```bash
python3.12 -m linguaflow.hardware
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python scripts/install_runtime.py
.venv/bin/python scripts/install_mlx.py
(cd desktop && npm ci && npx install-electron --no && npm run build)
.venv/bin/python -m linguaflow
```

前端准备需 Node.js（当前 CI 使用 24）；涉及前端的源码更新后也须重新准备并构建。之后用 `run-macos.command`。源码桌面使用 `.venv`；WLK 和 MLX 由安装器独立管理，应用通过 `runtime_paths.py` 定位，仍兼容已有 `.venv-wlk` / `.venv-mlx`。不需重复安装已兼容组件，也不要手动搬动环境目录。

## 模型与首次录音

1. 点击新录音直接准备聆听；默认名称可点顶部标题修改，开始前不创建文件。
2. 缺模型时按引导准备，也可到“设置 → 模型管理 → 下载模型…”。界面的推荐组合按平台给出：Qwen3-ASR 1.7B + HY-MT2 1.8B Q4_K_M；Mac 识别使用 MLX 4-bit、翻译使用 Metal，Windows 使用 CUDA。具体目录和选择以模型管理为准；推荐不代表所有语言和设备均已验收。SaT 随识别模型准备；Qwen 要指定原文语言。
3. 选择声音来源、语言，按需启用翻译，点击“开始聆听”。下载完成不自动录音；仅查看或单独下载不改变当前选择。

双击已下载模型可修改下一会话的模型/设备和高级参数；两种翻译引擎分别保存选择。Whisper 需要兼容权重，旧 faster-whisper/CTranslate2 目录不可直接使用。导入 GGUF 或填写 `hf://作者/仓库/文件.gguf` 不保证架构和聊天模板兼容，失败按提示换兼容文件，不静默改设备。

当前源码首次运行会选好平台推荐组合，原文默认 English；已有配置不被替换。Qwen 的语言列表不显示“自动检测”，明确选择的语言在切换引擎后保留。仅缺翻译组件时可先开始识别，界面会提示“本次仅识别”；准备完成后，下一次录音恢复原来的翻译选择，主动关闭翻译则保持关闭。

安装环境时显示“创建独立运行环境”“安装所需组件”“检查组件是否完整兼容”“验证运行环境”等阶段；首次安装可能需要几分钟，阶段耗时仅在收到进度时刷新，不作为下载百分比。原始安装日志不混入进度提示，失败仍会显示原因和下一步。

首次引导点击下载后进入模型管理；详细进度和取消入口只在该页显示，其他页面用右上进度通知。收起通知不取消下载，同一任务不反复弹出。取消后有效缓存保留；缺文件重新准备，组件异常用“运行环境”修复。点击开始录音会立即连接所选来源并写入音频，同时在后台校验和加载模型；首个音频块保存后显示“已开始录音，正在加载识别模型”。模型就绪后先处理积压，再依据处理进度显示实时识别；加载期间可暂停或停止，停止后会等待已有音频处理，失败或超时保留录音。显式模型检查可从“更多操作 → 取消模型检查”取消，不阻挡开始录音。出现“本地模型检查未完成”时，先核对模型位置和运行环境再重查；检查失败不等于权重丢失，已有有效模型不必重下。

## 录音、回顾与保存

- 进入左右分屏时，主录音侧栏动画收为 36 宽图标栏（与顶部拖动栏等高），录音条目折叠进文件夹；悬停图标会显示完整文件夹名气泡，点击文件夹只选择文件夹。“新录音”下面可手动收起/展开，展开恢复原侧栏宽度与文件夹状态。展开时按钮保留整行宽度、高度固定 36px；收起时为 36×36px 图标按钮。“新建文件夹”使用文件夹加号图标并提供名称提示，区别于“新录音”。普通缩窗和录音状态变化不自动切换；退出分屏保持当前选择，减少动态效果开启时直接切换。分屏按窗口贴左右边缘并占满屏幕可用高度的几何识别。收起状态进入设置时导航栏平滑展开，返回后仍保持收起。
- 聆听时可切换来源；暂停后选择在继续时生效。过渡和收尾期间暂不可切换。设备失效需重新选择，不自动换麦克风；空闲隐藏音量条，聆听显示音量，暂停归零。
- Mac 源码支持“系统音频 · 电脑声音”，开始时申请系统录制权限；不保存屏幕图像，无需 BlackHole，已有虚拟输入仍可用。权限拒绝后到系统“隐私与安全性 → 屏幕与系统音频录制”允许并重开；源码权限归属当前 Python 应用。安装包最低系统仍为 macOS 15，实际可用性以对应包验收为准。
- 点击左侧“新录音”直接进入待录音工作区，按下开始即可聆听。小岛只显示音频来源、语言、文件夹图标，点开可选；空白区列出当前来源、保存文件夹与语言。点击顶部标题改名，聆听中也可修改；真正开始前不写入空录音。
- 没有文件夹时，打开库、点击“新录音”或点开保存文件夹选择会自动创建并选中“我的录音”，无需先手动建目录；已有文件夹时沿用可用目录。
- 暂停/继续沿用同一文件，不保存暂停时间；停止处理尾部再保存。聆听中需先停止再切换录音；切换和退出前等待保存与资源释放。出现保存失败时保留窗口，按下文重试和备份，不反复强退。
- 左侧真实文件夹管理录音，行内“＋”创建子项，右键/“···”操作；聆听中可管理其他录音，当前录音及其所在文件夹不能移动或删除。删除进入垃圾桶，恢复保护同名文件，永久删除需确认；“最近删除 → 全部删除…”可一次清理当前列表，受保护或失败项目会保留并提示；旧 `.最近删除` 继续可读。
- Windows 和 Mac 都从侧栏“最近删除”恢复或永久删除。保存目录中的“垃圾桶”在第一次删除时建立，不是系统废纸篓；还没有删除过内容时，磁盘上没有该目录是正常情况。
- 已结束的空录音显示“无内容”；聆听、暂停和来源故障分别显示对应提示。
- 长录音可用“查看更早的字幕 / 查看较新的字幕”翻页，搜索结果和回听位置会载入对应字幕。回听可点击字幕或拖动进度定位，手动翻阅暂停跟随，方向箭头返回播放位置。音量可放大至 300%，不改原文件或系统音量；格式不支持时会提示。查找只定位，时间不保证逐字准确。
- 从右上角“··· / 更多操作 → 导出定稿”导出 SRT/TXT/Markdown；“悬浮字幕”也从同一菜单开启，标题栏不再并排显示这两个按钮。导出须已停止录音且存在非空、确认定稿的原文，保留已有译文及初译标记。仅有草稿时可使用“备份全部文字”。未完整结束会在录音状态中标注，普通导出仍只含定稿；重要录音请备份，强杀可能丢失尚未落盘的最近文字。
- 改保存位置须选择空目标，由后台复制、校验再切换；取消/失败保留原件。迁移进度持续显示，收起后仍可从“更多操作 → 取消录音库迁移”取消。默认位置及旧库兼容见 [目录地图](PROJECT_STRUCTURE.md#源码与数据)，不要自行删除旧库或运行目录。

## 课程资料与笔记

在“设置 → 常规”开启“体验 Beta 功能”，选中录音后打开“课程资料与笔记”。默认关闭；关闭保留已有材料和笔记，不中断正在运行的本地录音。

1. 关联课程并导入完整静态材料。支持 PDF、常见 Office/OpenDocument、离线 HTML、Markdown、TXT/CSV/TSV 和常见图片；只读取可呈现静态页/分片，不承诺动画、隐藏内容或网页交互。
2. 源码桌面环境需另装 `.[knowledge]`，可将上面的桌面安装命令改为 `.[dev,knowledge]`。PDF/Office 原页渲染另需 Node.js 22.19 或更新版本及渲染组件；在“运行环境 → 安装/修复课件渲染组件”准备，或由桌面 `.venv` 的 Python 执行 `scripts/install_documents.py`。网页/文本/图片复用包内 Electron，无需另装浏览器。组件准备需要网络；本地导入不发送云请求。
3. 要云端阅读，配置系统凭据中的 DeepSeek 密钥并允许本课程图文上传，点击“完整阅读并提取术语”。每页保存，取消后可复用有效结果；完整读完才启用课程云端笔记/问答。
4. 审核候选术语并保存，供下次 Qwen 录音使用。切换课程或录音保留本次运行中的草稿；退出前未保存会询问是否放弃，也会阻止更新重启。保存成功前不应用编辑。上下文超出预算的项会在界面显示，具体限制由 [课程配置](../linguaflow/knowledge/schemas.py) 维护；不改变已开始录音的快照。
5. 笔记用途另行授权，仅处理已保存定稿及相关课件；个人编辑不会被 AI 覆盖，来源变化会提示核对。引用可回原页/估计时间；失效 AI 内容不作为当前结论导出。

PDF/PPTX 导入先提取可用文字，点击“准备本地原页”可离线生成预览，无需云端许可。其他支持格式导入时生成页面；文本/网页同时保留可见文字及分片位置，旧的空文字快照需重新导入。扫描图像可能没有原生文字；模型解读单独标注，不当作原话引用。切页从顶部开始，缩放同页保留阅读位置。

网页依赖须在材料同目录或子目录且可离线读取；资源不全、容量超限或缓存损坏时按提示补齐、分章或重新导入，不把部分完成当作完整阅读。当前课程云端笔记、整理与问答均要求所关联材料完整读完，包括局部问题；局部放宽仍待评估。撤回许可会取消任务并阻止后续请求，已发送内容无法撤回；不上传音频。真实云端理解和笔记质量尚待验收，来源逐轮校验等实现缺口见 [ROADMAP](ROADMAP.md#实现缺口)。

## 显示、更新与常见问题

- “减少动态效果”关闭动画，保留自动跟随；上翻停止跟随，可返回最新内容。悬浮字幕可移动/缩放，背景透明度不降低文字不透明度。
- 检查更新与模型下载独立，录音和未保存期间不安装/重启；源码版只提示源码更新。Mac 0.9.0→0.9.2 线上升级已验收，beta.2 及更早包需手动过渡；Windows 预览包按发行说明手动安装。
- 手动检查立即显示进行中状态，最近结果和重试入口在“设置 → 运行环境”。重复点击查看同一任务，取消不再显示旧回调；可用更新以已验收平台的在线订阅为准。
- 无声音先核对所选来源、静音及系统权限；模型失败核对格式、设备和组件，勿把错误当成自动 CPU 回退。
- 保存失败时保留当前窗口和录音目录，检查磁盘空间、目录权限及位置可用性。通知中的“重试保存”不自动过期；收起后可从录音顶部“···”选择“重试保存录音”或“备份全部文字（含草稿）…”，将文字保存到其他可写位置。恢复 TXT 包括草稿、即时原文和已有译文，并标明未完成/过期状态；它不含音频，也不代表原录音保存成功。原录音保护锁会保留，重试成功后释放；若无法恢复原保存，可在成功备份后选择“使用文字备份关闭录音…”，核对提示并确认关闭，原目录及已有音频保留。取消、失败或过期备份不会解除保护。普通 SRT/TXT/Markdown 定稿导出仍排除草稿。

具体行为要求见 [spec](specs/README.md)，验证边界见 [VALIDATION](VALIDATION.md)。旧 LinguaFlow 启动入口、偏好及录音保持兼容。


## Electron 源码入口

正式入口为 Electron，Python 后台不再依赖 Qt。安装桌面 Python 依赖后，在 `desktop/` 执行 `npm ci` 和 `npm run build`，再使用原来的 `python -m linguaflow` 入口。旧录音格式不变，旧偏好首次读取后转存原子 JSON，原文件保留。

Qt 界面不再进入安装包，`--frontend qt` 会提示退役。只有执行旧界面开发对照时才安装 `.[dev,legacy-qt]`，正式依赖不需要它。采集继续使用 SoundCard / ScreenCaptureKit；回听、课件图片与网页渲染复用 Electron。

录音保护期间只能运行隔离无音频验证，不能直接启动普通工作区或发现设备。测试入口见 [TESTING](TESTING.md#electron-正式入口)：`npm test`、`npm run test:chain`、`npm run test:interaction` 和 `npm run test:audio-adapter`。原生更新仍由 Python 后台及 Sparkle/WinSparkle 负责。
