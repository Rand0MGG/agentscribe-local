# 本地录音工作区

左侧以真实文件夹整理录音。文件夹标题旁的“＋”创建文件夹；每个文件夹行内的“＋”在该文件夹中新建录音。新录音必须先填写名称、确认文件夹，创建后再点击“开始聆听”。点击左上角“新录音”也会进入相同的命名步骤，取消不会创建文件。

右键或行末“···”可新建录音、建立子文件夹、重命名、移动、打开磁盘位置和删除。双击文件夹折叠或展开。各层标记均为同尺寸的中性灰色竖直圆角细条，选中背景统一绘制，不采用系统强调色块。

音频来源、语言与模型管理从左下角“设置”进入，音频处理自动在后台完成。设置为独立页面：左侧返回与分类搜索，右侧分组设置和开关，返回录音时保存偏好。顶部提供课程资料与笔记、悬浮字幕和导出定稿，诊断记录、复制、刷新文件列表与保存位置收在“···”菜单。

## 保存与恢复

- **默认位置是安装目录下的 `录音` 文件夹**；未打包开发版对应项目目录下的 `录音`。设置 → 常规 → 录音保存位置可以打开或更改目录。默认位置不可写时明确提示选择其他位置，不会静默改存 AppData。打包安装包本身尚未制作，本次已实现运行时路径选择。
- 文件结构是 `录音/文件夹名称/录音名称/录音.wav`、`定稿.txt`、`定稿.srt` 和 `session.json`。文件列表没有数据库或中央索引，从目录扫描；可选课程笔记在录音旁保存独立的来源数据库，见下文。普通播放器和文本编辑器可直接打开音频与定稿。
- 更改保存目录只切换当前使用的目录，旧文件保留原位；切回旧目录即可查看。可在停止录音后通过资源管理器复制备份。外部改名或移动后使用“刷新文件列表”，以磁盘上的名称为准。手工改过的 TXT/SRT 不会因单纯浏览会话而被重新覆盖。
- 每段录音保存单声道 16-bit PCM WAV、完整字幕状态、设置快照，以及仅包含定稿的双语 TXT/SRT。48 kHz 录音约 346 MB/小时。
- 字幕每约 1.5 秒提交后台自动保存；停止后再次保存。同一录音的磁盘写入串行执行，待保存版本合并为最新快照，保存过程中新增的字幕仍标记为未保存。停止、切换录音和关闭窗口会等待写入完成，期间界面继续处理事件；等待超时或写入失败时保留字幕并提示重试/导出备份。重启后点击侧栏录音即可读取字幕与回听音频，播放条支持拖动定位。
- 草稿也保留，但不会混入定稿导出。异常或中断的会话显示“未完整结束”，不会冒充已完成结果。
- 字幕 JSON 采用临时文件替换，保存失败会保留此前文件并提示导出备份。强制结束进程仍可能丢失最近尚未保存的字幕。
- 关闭正在录音的窗口会先停止采集并处理剩余任务。加载中的会话仍支持取消。
- 新建或移动发生重名时自动添加序号，重命名发生冲突时拒绝覆盖；同时校验 Windows 保留名称与非法字符。文件夹不能移动到自身或其子文件夹。
- 删除先移至同一保存根目录内的 `.最近删除`，可以恢复；恢复时仍保护同名文件。最近删除中的“永久删除”需要再次确认，删除后无法恢复。
- 录音中禁止切换、改名、移动或删除；录音使用文件锁，避免另一应用窗口覆盖或移动正在使用的会话。音频设备缺失时要求重新选择，不会静默改用另一个麦克风。
- 旧版 `library.json` 保存结构会复制迁移，原件保留；迁移可以在部分失败后重试，已复制的会话不会再次导入。旧文件不会自动删除。

## 课程资料与笔记

该入口是当前 Windows 工作区中的试验实现，尚未提交发布。PDF / PPTX 在本地提取原生文本，按实际幻灯片顺序保留页码；图片、公式、空白和提取失败页提示核对。扫描页没有 OCR，复杂图表不宣称已经解析。课程资料跟随真实文件夹保存在 `.agentscribe/`，可手工录入术语，无需配置密钥或允许云端。

候选术语默认不使用。审核并保存后，最多 50 个术语/别名、512 UTF-8 字节的共享上下文用于下一次 Qwen 录音；未纳入的词显示在页面中。这个字节上限是保守输入预算，不是实测最佳热词数量。PyTorch 和 MLX 分别使用原有接口的 `context` / `system_prompt`，Whisper 不应用课程提示。录音开始后固定快照；资料、审核和重新关联入口在录音中禁用。参数生效的模拟检查不代表准确率提高或 Mac GPU 验收。

课件提词和录音笔记分别授权。点击“配置 DeepSeek 密钥”将其保存到 Windows / macOS 系统凭据存储；系统后端不可用时明确失败，不改存明文。开启笔记后发送已保存定稿、相关课件和已有笔记文字；课件分批提词，只缓存校验通过的候选，取消/超额保留先前完成批次。音频不会发送，应用关闭框架 tracing。关闭许可停止后续请求，已经发送的内容无法撤回。

自动笔记在有成功保存的定稿时开始，正常更新间隔至少 30 秒；停止保存后处理剩余来源，不等待最低字幕条数。失败或取消暂停自动任务，点击“更新笔记”可继续。草稿、重新打开但尚未确认的原文、未成功保存的版本不参与发布。旧笔记记录课件/字幕来源和版本；直接引用变化显示“来源已变化”，相关新讲述显示待核对，模型必须处理本批旧笔记后才能发布。词项检索与最近讲述复核无法保证发现所有跨语言或远距离纠正，内容仍需核对。个人编辑会锁定条目，后续模型不得覆盖；引用过期时仍保留个人文字和提示。

点击引用可查看对应课件页，或定位录音的估计时间，不自动播放。课后整理使用受限 Deep Agents，可选择已有笔记章节；提问通过原文检索和带页内范围的读取获取证据。所有内部模型调用都受单次任务最多 12 请求、64,000 tokens（含保守预留）、16,000 UTF-8 字节请求输入限制；单次输出最多 2,048 tokens。上限是防止失控的工程预算，不是服务商费用报价。用量缺失时显示不确定预留，失败不自动重试。超长输入需按章节处理，不能据此声称完成全课覆盖。

录音旁的 `knowledge/manifest.json` 保存课程稳定 ID、审核上下文和许可；实际录音使用的快照仍在 `session.json` 的 settings。`knowledge/state.sqlite` 维护可重建的来源版本、笔记与处理状态，数据库连接按事务关闭，不取代录音保存。任务审计只保留有限的来源版本元数据，不重复保存整份课件和全文。导出 `课堂笔记.md` 包含有效 AI 笔记和个人编辑；待核对或失效 AI 内容不作为当前结论导出。

重命名、移动、最近删除和退出先停止自有课程后台；外部移动或替换后拒绝迟到结果，重新打开恢复。录音移到其他文件夹仍引用原课程，只有“使用此课程”才重新关联，并关闭本段云端笔记许可。课程缺失或原件/缓存损坏时暂停云任务，旧笔记保留，可恢复资料或重新关联；已保存的字幕与录音继续可用。永久删除课程资料时，若其他录音（包括最近删除中的录音）仍引用它，则阻止删除，不扩大删除范围。

## 显示

字幕改为连续排版。未定稿原文使用较淡颜色，真实模型修订直接替换文字；定稿后恢复正常亮度。不再显示替换、撤回或合并说明，不用模拟打字制造输出。

玻璃区域使用经过柔化与压暗的桌面壁纸背景，而非实时透视其他窗口。内容区左上角使用一条连续绘制的圆弧边界。悬浮字幕保留原文、已有译文和关闭入口，可拖动窗口背景移动。

## 验证

`scripts/preview_workspace.py --capture` 在 `.work/workspace-preview` 使用隔离的示例字幕、静音音频和设置，不采集麦克风或修改正常录音库。主界面、窄窗口、设置和悬浮字幕截图输出至 `.work/browser`。

本次回归涵盖命名到保存、会话重开、草稿与定稿区分、外部改名、保存失败恢复、目录移动、删除与恢复、永久删除范围保护、旧数据迁移、录音 PCM 长度，以及原有字幕/进程生命周期。界面预览采用示例数据，不作为新的识别准确率或长时间录音性能证据。

2026-10-03 自动检查额外发现 Windows / Python 3.11 在非中文 locale 下将中文直接传给 `strftime()` 会导致默认命名失败。文件库和新建对话框现共用不经过 locale 格式化的中文默认名称；日期格式保持原样，旧文件不重命名。保存收尾期间继续禁用录音操作，嵌套 Qt 保存等待结束后再安排会话对象释放，未完成的磁盘写入继续持有录音锁。动画回归使用可控帧时间检验原有中间位置及手动中断断言，避免依赖 CI 主机在固定 70 ms 内调度计时器。
