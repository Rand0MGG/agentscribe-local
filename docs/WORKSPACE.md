# 安装与使用指南

本文描述当前源码操作和已知限制；旧安装包以其发行说明为准。目标行为见 [spec](specs/README.md)，实现缺口见 [ROADMAP](ROADMAP.md#实现缺口)，平台证据见 [VALIDATION](VALIDATION.md)。核心识别与翻译在组件和模型准备后可断网使用，课程云任务需要网络及用途许可。

## 安装与首次准备

### Mac 安装包

从 [beta.2 发行页](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.6.0-beta.2) 下载 DMG，拖入 Applications。支持原生 Apple Silicon/macOS 15+，不支持 Intel/Rosetta；包内有桌面依赖，无需自行安装桌面 Python。当前预览包未 Developer ID 签名/公证，系统拦截时按发行说明操作，不全局关闭安全保护。

打开后在设置准备运行组件与模型，首次需要网络和磁盘空间。当前源码比该包新，勿把本指南所有入口当作 beta.2 已有功能。

### Windows 源码安装

下载 [Windows 分支](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/windows.zip)，安装 Python 3.12，在项目目录执行：

```powershell
py -3.12 -m linguaflow.hardware
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe scripts\install_runtime.py
.venv\Scripts\python.exe -m linguaflow
```

本指南使用 Python 3.12，支持范围以 [pyproject.toml](../pyproject.toml) 为准。完整推理环境要求 Windows x64 和兼容的 NVIDIA GPU/驱动；最低计算能力与驱动要求由 [硬件检查](../linguaflow/hardware.py) 维护，以上首条命令会给出检查结果。检查失败先解决提示，不继续安装或回退 CPU。之后可用 `run-windows.cmd`；无需 WSL 或手动启动服务。尚无已发布 Windows 安装包。

### macOS 源码安装

下载 [Mac 分支](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/mac.zip)，在原生 Apple Silicon 项目目录执行：

```bash
python3.12 -m linguaflow.hardware
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python scripts/install_runtime.py
.venv/bin/python scripts/install_mlx.py
.venv/bin/python -m linguaflow
```

之后用 `run-macos.command`。源码桌面使用 `.venv`；WLK 和 MLX 由安装器独立管理，应用通过 `runtime_paths.py` 定位，仍兼容已有 `.venv-wlk` / `.venv-mlx`。不需重复安装已兼容组件，也不要手动搬动环境目录。

## 模型与首次录音

1. 点击新录音直接准备聆听；默认名称可点顶部标题修改，开始前不创建文件。
2. 缺模型时按引导准备，也可到“设置 → 模型管理 → 下载模型…”。界面的推荐组合按平台给出：Qwen3-ASR 1.7B + HY-MT2 1.8B Q4_K_M；Mac 识别使用 MLX 4-bit、翻译使用 Metal，Windows 使用 CUDA。具体目录和选择以模型管理为准；推荐不代表所有语言和设备均已验收。SaT 随识别模型准备；Qwen 要指定原文语言。
3. 选择声音来源、语言，按需启用翻译，点击“开始聆听”。下载完成不自动录音；仅查看或单独下载不改变当前选择。

双击已下载模型可修改下一会话的模型/设备和高级参数；两种翻译引擎分别保存选择。Whisper 需要兼容权重，旧 faster-whisper/CTranslate2 目录不可直接使用。导入 GGUF 或填写 `hf://作者/仓库/文件.gguf` 不保证架构和聊天模板兼容，失败按提示换兼容文件，不静默改设备。

首次引导点击下载后进入模型管理；详细进度和取消入口只在该页显示，其他页面用右上进度通知。收起通知不取消下载，同一任务不反复弹出。取消后有效缓存保留；缺文件重新准备，组件异常用“运行环境”修复。环境修复与模型下载分开，已有有效模型不必重下。当前检查进程失败时仍可能显示“缺模型”；出现“本地模型检查未完成”或已有权重却反复提示缺失时，先检查模型位置和运行环境，再重新检查，不要据此认定权重已丢失。

## 录音、回顾与保存

- 聆听时可切换来源；暂停后选择在继续时生效。过渡和收尾期间暂不可切换。设备失效需重新选择，不自动换麦克风；空闲隐藏音量条，聆听显示音量，暂停归零。
- Mac 源码支持“系统音频 · 电脑声音”，开始时申请系统录制权限；不保存屏幕图像，无需 BlackHole，已有虚拟输入仍可用。权限拒绝后到系统“隐私与安全性 → 屏幕与系统音频录制”允许并重开；源码权限归属当前 Python 应用。安装包最低系统仍为 macOS 15，实际可用性以对应包验收为准。
- 点击左侧“新录音”直接进入待录音工作区，按下开始即可聆听。小岛只显示音频来源、语言、文件夹图标，点开可选；空白区列出当前来源、保存文件夹与语言。点击顶部标题改名，聆听中也可修改；真正开始前不写入空录音。
- 没有文件夹时，打开库、点击“新录音”或点开保存文件夹选择会自动创建并选中“我的录音”，无需先手动建目录；已有文件夹时沿用可用目录。
- 暂停/继续沿用同一文件，不保存暂停时间；停止处理尾部再保存。聆听中需先停止再切换录音；切换和退出前等待保存与资源释放。出现保存失败时保留窗口，按下文重试和备份，不反复强退。
- 左侧真实文件夹管理录音，行内“＋”创建子项，右键/“···”操作；聆听中可管理其他录音，当前录音及其所在文件夹不能移动或删除。删除进入垃圾桶，恢复保护同名文件，永久删除需确认；“最近删除 → 全部删除…”可一次清理当前列表，受保护或失败项目会保留并提示；旧 `.最近删除` 继续可读。
- Windows 和 Mac 都从侧栏“最近删除”恢复或永久删除。保存目录中的“垃圾桶”在第一次删除时建立，不是系统废纸篓；还没有删除过内容时，磁盘上没有该目录是正常情况。
- 已结束的空录音显示“无内容”；聆听、暂停和来源故障分别显示对应提示。
- 长录音可用“查看更早的字幕 / 查看较新的字幕”翻页，搜索结果和回听位置会载入对应字幕。回听可点击字幕或拖动进度定位，手动翻阅暂停跟随，方向箭头返回播放位置。音量可放大至 300%，不改原文件或系统音量；格式不支持时会提示。查找只定位，时间不保证逐字准确。
- 导出定稿为 SRT/TXT/Markdown，保留已有译文及初译标记。未完整结束会在录音状态中标注，普通导出仍只含定稿；重要录音请备份，强杀可能丢失尚未落盘的最近文字。
- 改保存位置须选择空目标，由后台复制、校验再切换；取消/失败保留原件。默认位置及旧库兼容见 [目录地图](PROJECT_STRUCTURE.md#源码与数据)，不要自行删除旧库或运行目录。

## 课程资料与笔记

在“设置 → 常规”开启“体验 Beta 功能”，选中录音后打开“课程资料与笔记”。默认关闭；关闭保留已有材料和笔记，不中断正在运行的本地录音。

1. 关联课程并导入完整静态材料。支持 PDF、常见 Office/OpenDocument、离线 HTML、Markdown、TXT/CSV/TSV 和常见图片；只读取可呈现静态页/分片，不承诺动画、隐藏内容或网页交互。
2. 源码桌面环境需另装 `.[knowledge]`，可将上面的桌面安装命令改为 `.[dev,knowledge]`。PDF/Office 原页渲染另需 Node.js 22.19 或更新版本及渲染组件；在“运行环境 → 安装/修复课件渲染组件”准备，或由桌面 `.venv` 的 Python 执行 `scripts/install_documents.py`。网页/文本/图片复用 Qt，无需另装浏览器。组件准备需要网络；本地导入不发送云请求。
3. 要云端阅读，配置系统凭据中的 DeepSeek 密钥并允许本课程图文上传，点击“完整阅读并提取术语”。每页保存，取消后可复用有效结果；完整读完才启用课程云端笔记/问答。
4. 审核候选术语并保存，供下次 Qwen 录音使用。同一面板内切换课程会分别保留未保存编辑，切回原课程可继续；保存成功后才确认审核结果。上下文有项数及 UTF-8 字节预算，超出项在界面显示；具体限制由 [课程配置](../linguaflow/knowledge/schemas.py) 维护。不是越多越准，也不改变已开始录音的快照。
5. 笔记用途另行授权，仅处理已保存定稿及相关课件；个人编辑不会被 AI 覆盖，来源变化会提示核对。引用可回原页/估计时间；失效 AI 内容不作为当前结论导出。

当前本地预览按格式不同：PDF/PPTX 导入先提取可用文字，扫描 PDF 可能没有文字；这两类文件的原页图片由允许图文上传后的“完整阅读”任务生成，尚无独立的离线原页预览入口。其他支持格式在本地导入时生成页面图片，可离线查看；TXT、Markdown、HTML 等目前未将可读文字写入原生来源块，界面“原生文字”可能为空。原件仍保留，模型视觉解读须对照原页，不能当作原话引用。

网页依赖须在材料同目录或子目录且可离线读取；资源不全、容量超限或缓存损坏时按提示补齐、分章或重新导入，不把部分完成当作完整阅读。当前课程云端笔记、整理与问答均要求所关联材料完整读完，包括局部问题；局部放宽仍待评估。撤回许可会取消任务并阻止后续请求，已发送内容无法撤回；不上传音频。真实云端理解和笔记质量尚待验收，来源逐轮校验等实现缺口见 [ROADMAP](ROADMAP.md#实现缺口)。

## 显示、更新与常见问题

- “减少动态效果”关闭动画，保留自动跟随；上翻停止跟随，可返回最新内容。悬浮字幕可移动/缩放，背景透明度不降低文字不透明度。
- 检查更新与模型下载独立。安装版由对应原生更新器处理，录音和未保存期间不安装/重启；源码版只提示源码更新。已发布 beta.2 无应用内安装能力，需一次手动过渡。
- 手动检查立即显示进行中状态；检查失败可在通知中查看详情并重试，设置的运行环境页保留最近结果。重复点击查看同一任务，取消不再显示旧回调；可用更新以已验收平台的在线订阅为准。
- 无声音先核对所选来源、静音及系统权限；模型失败核对格式、设备和组件，勿把错误当成自动 CPU 回退。
- 保存失败时保留当前窗口和录音目录，检查磁盘空间、目录权限及位置可用性。通知中的“重试保存”不自动过期；收起后可从录音顶部“···”选择“重试保存录音”或“备份全部文字（含草稿）…”，将文字保存到其他可写位置。恢复 TXT 包括草稿、即时原文和已有译文，并标明未完成/过期状态；它不含音频，也不代表原录音保存成功。原录音保护锁会保留，重试成功后释放；若无法恢复原保存，可在成功备份后选择“使用文字备份关闭录音…”，核对提示并确认关闭，原目录及已有音频保留。取消、失败或过期备份不会解除保护。普通 SRT/TXT/Markdown 定稿导出仍排除草稿。

具体行为要求见 [spec](specs/README.md)，验证边界见 [VALIDATION](VALIDATION.md)。旧 LinguaFlow 启动入口、偏好及录音保持兼容。
