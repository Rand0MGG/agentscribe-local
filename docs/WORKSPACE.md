# 安装与使用指南

## 安装与首次准备

### Mac 安装包

从 [v0.6.0-beta.2 发行页](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.6.0-beta.2) 下载 Apple Silicon DMG，将应用拖入 Applications。要求 macOS 15 或更新，不支持 Intel / Rosetta。当前包采用临时签名，未完成 Developer ID 签名与公证；系统阻止打开时按发行说明操作，不关闭系统安全保护。真实音频权限、采集、回听和长会话仍待完整安装态验收。

安装包与源码版的环境准备不同，安装包用户无需执行下面的桌面 Python 安装命令。打开应用后，按设置中的入口准备运行组件与模型；首次下载需要联网和额外磁盘空间。模型准备完成后，本地识别与翻译可以断网运行。

### Windows 源码安装

当前没有 Windows 独立安装包。安装 Python 3.12，下载并解压 [Windows 分支源码](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/windows.zip)，在项目目录打开 PowerShell。源码兼容 Python 3.11–3.13，开发优先使用 3.12。

硬件要求为 Windows x64、NVIDIA Turing 或更新架构（计算能力至少 7.5）及驱动至少 570.65；以实际安装前检查为准，不满足时拒绝准备环境，不回退 CPU。检查会调用显卡诊断工具，不访问音频设备。

```powershell
py -3.12 -m linguaflow.hardware
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
.venv\Scripts\python.exe scripts\install_runtime.py
.venv\Scripts\python.exe -m linguaflow
```

第一步失败时先解决提示中的硬件或驱动问题，不继续安装。之后可使用 `run-windows.cmd` 启动；`install-gpu-windows.cmd` 调用同一推理环境准备流程。不需要 WSL 或手动启动服务。

### macOS 源码安装

在原生 Apple Silicon 环境中下载 [Mac 分支源码](https://github.com/Rand0MGG/agentscribe-local/archive/refs/heads/mac.zip)，在项目目录运行：

```bash
python3.12 -m linguaflow.hardware
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python scripts/install_runtime.py
.venv/bin/python scripts/install_mlx.py
.venv/bin/python -m linguaflow
```

MLX 环境与 WLK 环境隔离，也可在设置中按需准备。之后使用 `run-macos.command` 启动。系统声音配置和设备权限见 [Mac 说明](MACOS_SUPPORT.md)；文件 GPU 测试不等于真实录音验收。

### 首次录音

1. 在设置 → 模型管理点击“下载模型…”，直接选择模型或下载推荐组合，无需设置引擎和参数。字幕分句组件随识别模型准备，Qwen 必须指定原文语言。
2. 按需选择翻译模型、引擎、设备与目标语言；也可以只显示原文。Whisper 使用兼容权重，旧 faster-whisper/CTranslate2 目录不能直接使用；GGUF 翻译模型准备见 [llama.cpp](LLAMA_CPP.md)。
3. 选择音频来源，新建并命名录音，然后点击“开始聆听”。暂停/继续写入同一录音；停止时处理尾部并保存。

桌面与推理依赖分别准备，不修改系统 Python。环境和模型下载完成后不需要反复安装；退出应用会清理自有后台进程。原名 LinguaFlow 的旧入口、偏好和录音保持兼容。

## 录音工作区

左侧以真实文件夹整理录音。文件夹标题旁的“＋”创建文件夹；每个文件夹行内的“＋”在该文件夹中新建录音。新录音必须先填写名称、确认文件夹，创建后再点击“开始聆听”。点击左上角“新录音”也会进入相同的命名步骤，取消不会创建文件。

右键或行末“···”可新建录音、建立子文件夹、重命名、移动、打开磁盘位置和删除。点击文件夹前的展开标记或双击文件夹可折叠、展开。文件夹与录音使用对应的线条图标，选中背景统一绘制，不采用系统强调色块。

音频来源、语言与模型管理从左下角“设置”进入，音频处理自动在后台完成。设置为独立页面：左侧返回与分类搜索，右侧分组设置和开关，返回录音时保存偏好。顶部提供悬浮字幕和导出定稿，开启 Beta 后才显示课程资料与笔记；诊断记录、复制、刷新文件列表与保存位置收在“···”菜单。

Mac 系统菜单栏的“AgentScribe”菜单提供“关于 AgentScribe”“版本与更新…”和“检查更新…”。关于窗口及设置的“运行环境 → 版本与更新”显示当前版本。应用打开后后台检查已发布版本；有适用新版时显示可稍后处理的提示，无更新或离线时保持安静。左下角设置按钮上方另有“检查更新”入口；手动检查打开该页并显示结果与发行页入口。检查不占用模型准备任务、不阻止录音；更新请求被限流或网络不可用时只在更新页显示简短提示，不向录音页写入异常堆栈。目前不自动下载安装或重启。

录音页底部悬浮小岛集中显示音频来源、原文与翻译语言，以及开始、暂停和结束操作。录音期间显示短音量条；打开有音频的录音时，同一位置显示播放／暂停图标、可拖动的回放进度和当前位置／总时长，隐藏开始聆听与声音源选择。向上翻阅时字幕可以从小岛下方经过，两侧仍可阅读；最后一段留出底部空间。窗口最小尺寸为 640 × 480（逻辑像素），宽高可独立调整，小岛在窄窗口中换行。Windows 标题栏与边缘调用系统移动／缩放，并保留系统吸附所需的窗口标记；Mac 使用原生标题栏，平铺取决于系统设置。标题区缩短高度，白色与深色使用同一布局；按钮、列表和设置导航统一使用更明显的悬停背景，选中背景进一步加深，不叠加按钮阴影。下拉选项统一绘制圆角、选中标记和省略文本，保留键盘操作。

设置并列显示常规、聆听、模型管理、字幕与延迟、运行环境和使用指南，可直接进入各模块或搜索。当前源码界面默认白色，可在常规设置切换深色。外层背景使用大范围扩散与较弱壁纸着色，阅读区保持不透明。

模型管理顶部可在已下载模型之间切换，本机开发阶段下载的兼容模型也会自动列出。“下载模型…”只列少量明确版本：Apple 芯片 Mac 提供 Qwen3-ASR 1.7B 的 4-bit、8-bit，以及 HY-MT2 1.8B Q4_K_M；推荐组合为 Qwen 4-bit 与 HY Q4_K_M。8-bit 接入现有 MLX 加载流程，尚待 Mac 实机验收。Windows 尚未接入 Qwen 量化识别后端，下载入口提供 Qwen 原始 1.7B 和 HY Q4_K_M，不把 Mac 权重当成 Windows 可用模型。单独下载沿用用户的设备选择，不改变当前模型配置；“下载并使用推荐组合”同时保存下次使用的两种模型，不自动开始录音。双击已下载模型查看本地位置、大小和对应引擎；参数、设备及导入入口收在“高级设置”。点击“使用此模型”后才保存下次聆听的配置。

下载窗口的“高级…”入口可选择兼容的 Whisper、Qwen3-ASR、HY-MT2 或 NLLB。GGUF 翻译可选择 HY-MT2 1.8B 的 Q4_K_M（4-bit）、Q6_K 或 Q8_0，也可填写 `hf://作者/仓库/文件.gguf` 下载单个兼容权重；下载进度与取消沿用同一个后台准备流程。自选 GGUF 不保证模型架构、提示词与当前 llama.cpp 兼容，开始聆听时仍校验。Windows 的 Qwen PyTorch 识别不支持 MLX 量化权重；MLX 量化选项只在 Apple Silicon Mac 引擎下提供。

删除应用管理的模型缓存前需要确认，录音或下载时不能删除；用户自选目录只显示和设置，删除请在文件管理器中处理。当前流程不下载或加载 ForcedAligner；列表中的对齐模型不能选作 ASR。目录检查不加载模型，删除不包含录音和字幕。当前源码界面变化不代表已发布安装包也包含这些变化。

悬浮字幕窗口独立置顶，中英文使用相同字号与字重。鼠标进入显示工具栏和右下角缩放手柄，移开后自动隐藏，字幕布局保持不动。工具栏用滑块调整字号和背景不透明度（0% 完全透明、100% 不透明），不再显示拖动提示；仍可拖动工具栏空白处移动窗口，文字保持清晰不透明。更新文字不会重置用户尺寸；关闭时保存窗口尺寸与位置，字号和背景设置即时保存。长字幕在窗口内换行，可滚动阅读。

字幕与延迟沿用当前参数，不提供未经性能对照验证的速度/均衡预设。高级时间参数表示请求或停顿检测目标，不是动态识别窗口长度。

运行环境只有“检查 / 修复运行环境”一个入口：根据所选引擎检查所需 Python 环境的依赖与 GPU 运算，并检查 llama.cpp 翻译组件能否启动，通过则复用，失败则重新校验并准备。未选择 MLX 时不额外安装 MLX。运行组件修复不下载模型权重。完成后清理未被当前或回退链引用且未被进程使用的管理目录；进程或引用状态无法确认时跳过清理。旧源码虚拟环境、基础 Python、模型与录音不在清理范围内。

手动检查更新独立于模型下载运行：检查中显示“正在检查更新”，无新版时明确显示“当前已是最新版本”；服务限流或网络失败显示可重试提示，不视为已经确认最新。重复点击检查不会并发请求。

模型准备统一放在“设置 → 模型管理”。后台下载卡片集中显示当前文件、百分比、下载大小、速度和取消操作；未知总大小使用不定进度，不显示虚假的百分比。切换设置页仍可查看和取消；返回录音页不影响后台任务。完成、失败或取消后保留结果提示与已有缓存。准备使用当前选择，不覆盖自定义模型；首次 Mac 准备采用 MLX 4-bit 与 HY Q4_K_M，已有偏好和刚修改的模型选择保留。

新建录音或点击“开始聆听”时在后台检查所需模型与组件，缺失时弹出可关闭的提示，提供“下载所选模型”和模型管理入口。新录音的名称和文件夹保留；开始聆听须等检查通过。关闭翻译时只检查和便捷准备识别所需文件。关闭提示后仍可去模型管理下载或导入，再次点击开始会重新检查；下载完成不自动开始录音。启动或浏览已有录音时的检查保持安静，不自动联网下载、不加载模型、不访问音频设备。准备完成或取消后重新检查文件，暂不按内存修改模型或配置。

翻译上下文固定为初译前后各 1 段、定稿前 5 段及后 1 段，参数不再开放修改；只使用当时已有的已定稿原文，没有后文立即处理。翻译与识别可以并行；新翻译推理只在字幕分句实际更新期间短暂等待，不要求识别输入队列清空。译文发布前核对当前原文与版本，原文变化后旧结果不能覆盖新字幕。录音期间可以修改下次使用的设置，当前会话继续使用启动时的配置。运行环境安装与修复会影响当前推理，须等本次录音结束后执行。

## 保存与恢复

- **新默认位置独立于程序目录**：Windows `%LOCALAPPDATA%\AgentScribe\录音`；Mac `~/Library/Application Support/AgentScribe/录音`。源码版也使用相同规则。设置 → 常规可以打开或更改目录。已有偏好优先；未设置偏好但项目内旧 `录音` 非空时继续使用并记住旧位置，不自动搬移文件。默认位置不可写时提示选择其他目录。目录分离已实现，真实卸载仍待验收；各平台安装包和升级状态只在 [发行流程](RELEASING.md#当前状态) 维护。旧项目内录音须在清理项目之前复制备份，不能当作安装缓存删除。
- 文件结构是 `录音/文件夹名称/录音名称/录音.wav`、`定稿.txt`、`定稿.srt` 和 `session.json`。文件列表没有数据库或中央索引，从目录扫描；可选课程笔记在录音旁保存独立的来源数据库，见下文。普通播放器和文本编辑器可直接打开音频与定稿。
- 更改保存目录只切换当前使用的目录，旧文件保留原位；切回旧目录即可查看。可在停止录音后通过资源管理器复制备份。外部改名或移动后使用“刷新文件列表”，以磁盘上的名称为准。手工改过的 TXT/SRT 不会因单纯浏览会话而被重新覆盖。
- 每段录音保存单声道 16-bit PCM WAV、完整字幕状态、设置快照，以及仅包含定稿的双语 TXT/SRT。48 kHz 录音约 346 MB/小时。
- 字幕每约 1.5 秒提交后台自动保存；停止后再次保存。同一录音的磁盘写入串行执行，待保存版本合并为最新快照，保存过程中新增的字幕仍标记为未保存。停止、切换录音和关闭窗口会等待写入完成，期间界面继续处理事件；等待超时或写入失败时保留字幕并提示重试/导出备份。重启后点击侧栏录音即可读取字幕与回听音频，播放条支持拖动定位。
- 点击「导出定稿」可选择 SRT、TXT 或 Markdown（`.md`）。三种格式仅导出确认定稿的原文，保留已有译文及「初译」标记；Markdown 额外显示每段时间范围。导出使用冻结快照在后台写入，失败保留已有目标文件，关闭窗口会等待导出结束。
- 草稿也保留，但不会混入定稿导出。异常或中断的会话显示“未完整结束”，不会冒充已完成结果。
- 字幕 JSON 采用临时文件替换，保存失败会保留此前文件并提示导出备份。强制结束进程仍可能丢失最近尚未保存的字幕。
- 关闭正在录音的窗口会先停止采集并处理剩余任务。加载中的会话仍支持取消。
- 新建或移动发生重名时自动添加序号，重命名发生冲突时拒绝覆盖；同时校验 Windows 保留名称与非法字符。文件夹不能移动到自身或其子文件夹。
- 删除先移至同一保存根目录内的 `垃圾桶`，可以恢复；恢复时仍保护同名文件。最近删除中的“永久删除”需要再次确认，删除后无法恢复。旧版 `.最近删除` 中的条目仍可查看、恢复或永久删除，软件不自动搬迁旧文件；若已有用户自建的同名“垃圾桶”文件夹，则提示改名，不覆盖其内容。
- 录音中禁止切换、改名、移动或删除；录音使用文件锁，避免另一应用窗口覆盖或移动正在使用的会话。音频设备缺失时要求重新选择，不会静默改用另一个麦克风。
- 旧版 `library.json` 保存结构会复制迁移，原件保留；迁移可以在部分失败后重试，已复制的会话不会再次导入。旧文件不会自动删除。

## 课程资料与笔记

课件解析、识别提示整理、课堂笔记与课后 agent 均划归 Beta。在“设置 → 常规”开启“体验 Beta 功能”后，才显示“课程资料与笔记 · Beta”入口；缺失或损坏的旧设置默认关闭。关闭会隐藏入口、关停课程后台并忽略旧录音的自动笔记许可，下一次录音不读取或应用课程术语；已有课件、审核结果和笔记保留。已经开始的录音继续使用其固定术语快照，关闭不会中断本地录音或修改该快照。重新开启 Beta 后，上传仍按课程和录音单独授权。

该功能处于 Beta，尚未完成真实云端课件质量验收。“导入课件”按文件格式选择本地处理方式，共用完整阅读、来源引用、审核术语和笔记流程；无需添加格式设置或安装整套 DSH。当前仍先新建或选择录音（可以是未开录草稿）再打开课程入口。

| 导入格式 | 模型看到的内容与来源位置 |
| --- | --- |
| PDF、PPT/PPTX/ODP、DOC/DOCX/ODT | 全部静态页/幻灯片图像；PDF/PPTX 另保留原生文本，其他 Office 格式不把转换或模型文字冒充原生提取 |
| XLS/XLSX/ODS | 全部可见工作表的数据区域，超过单图尺寸时分片；保留工作表名、A1 范围和分片位置，不限于打印区域。隐藏内容、批注和交互状态不属于页面读取 |
| HTML/HTM | 本地屏幕布局，包括图片、CSS、SVG、脚本绘制的 Canvas；横向和纵向溢出都分片，不使用可能隐藏内容的打印样式 |
| MD/Markdown、TXT、CSV/TSV | Markdown 按已有 Qt 的 GitHub 方言显示，保留本地图片；文本完整分页，CSV/TSV 保留引号内逗号、换行和表格单元格。Markdown 不执行额外 Mermaid/LaTeX 插件 |
| PNG/JPG/JPEG/WebP/GIF/BMP/ICO/SVG | 位图校验内容、方向和色彩后转为有尺寸上限的 PNG；SVG 本地渲染为图像。多帧位图仅默认静态首帧，不承诺读取动画 |

原件在本地保存。新增格式导入即生成可离线预览的页面快照；Office 页码、工作表范围和网页屏幕矩形随来源保存。网页/Markdown 的相关图片、字体、CSS 与静态 JS 模块必须在课件所在目录或其子目录；不通过父目录、链接映射或网络补齐。最多 64 个资源、单项 4 MiB、课件及资源总量 32 MiB；网页/文本原件最多 4 MiB，支持 UTF-8 或带 BOM 的 UTF-16。资源缺失、脚本错误、外部页面或音视频明确失败，请提供完整离线静态版。运行时动态取数或交互、隐藏或折叠内容需要先展开/导出；静态截图不承诺遍历所有交互状态。

导入先使用私有原件快照，把完整结果写到独立版本目录，完成全部页面和容量校验后切换课程引用；失败、取消或强制结束进程保留可读的旧版材料。未发布目录和历史版本保留，不自动清理。网页资源单独保留不可变快照，修改外部资源后需重新导入。即使主文件未变，资源变化也会更新来源版本，使旧解读/笔记失效；页面或资源缓存损坏时要求重新导入，不将损坏缓存视为完整。旧材料目录继续兼容。课程资料跟随真实文件夹保存在 `.agentscribe/`，可手工录入术语，无需密钥或云端。

网页固定栏、吸顶栏在截图前放回静态排版，避免遮住滚动分片的正文；栏内内容仍保留。旧布局版本的网页快照需重新导入，重新阅读后才能用于笔记。

源码版需向桌面环境安装可选依赖 `.[knowledge]`；PDF/Office 还需 Node.js 22.19 或更新版本。启用 Beta 后，在设置的“运行环境”页点击“安装 / 修复课件渲染组件”；也可用桌面解释器运行 `scripts/install_documents.py`。关闭 Beta 会隐藏此入口并取消尚在执行的组件安装，已完成文件保留。Mac DMG 已包含桌面可选依赖与 Node，PDF/Office 引擎仍需按对应发行说明准备；新入口属于本次源码改动，不会修改已发布的旧 DMG。安装器在共享运行目录的 `components/document-renderer` 中准备独立 `@deepseek-ai/libreoffice-kit@0.1.3`，校验后才切换；兼容旧 `.runtime/document-renderer`。历史 Windows x64 组件及依赖约 197 MiB。网页、文本和图片复用已有 PySide6；Qt WebEngine 在私有、非持久化、禁止联网的自有子进程中使用 CPU 截图，不增加浏览器下载、OCR 或附件数据库。内存峰值尚未评测；Mac beta 已有包内网页与公开 PPT 样本渲染记录，具体范围见 [发行说明](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.6.0-beta.1)，不等于所有格式或真实课件云端理解通过。

配置 DeepSeek 密钥，勾选“允许将本课程的页面图像和文字发送给 DeepSeek，完整阅读课件”，点击“完整阅读并提取术语”。模型逐页查看完整图像，原生文本作为辅助；扫描页、图表、公式、空白页均计入覆盖，不靠文字是否非空决定跳过。原页与“模型视觉解读”分别展示，解读单独保存、单独引用，不改写原生文字。含疑问的页明确标注；“已读 N/N 页”表示全部静态页/分片成功完成请求和结果校验，不保证理解无误。当前不读取 Office 动画、嵌入视频或任意网页交互状态。

完成一页即缓存结果；取消、失败或重开后，再次点击读取会验证原件、渲染版本、模型/提示版本及图片校验值，复用已完成页。尚有未读页时暂停基于该课程的云端笔记、整理和问答，提示先完成读取。已有术语与本地录音仍可使用。模型每次只接收当前页或相关页，不需要把整份课件塞进一次请求。笔记检索完整解读；长解读使用明确标注的相关摘录，并附完整原页，避免长页被预算直接排除。完整解读仍保留，课后工具可分段读取和重新查看原页。

候选术语默认不使用。审核并保存后，最多 50 个术语/别名、512 UTF-8 字节的共享上下文用于下一次 Qwen 录音；未纳入的词显示在页面中。这个字节上限是保守输入预算，不是实测最佳热词数量。PyTorch 和 MLX 分别使用原有接口的 `context` / `system_prompt`，Whisper 不应用课程提示。未开始录音的草稿在启动时读取关联课程的最新审核词表，移动草稿不改变课程归属；已开始录音的快照保留。录音开始后固定快照；资料、审核和重新关联入口在录音中禁用。参数生效的模拟检查不代表准确率提高或 Mac GPU 验收。

课件图像与文字和录音笔记分别授权；历史仅文字许可默认不授权图像，需重新勾选。点击“配置 DeepSeek 密钥”将其保存到 Windows / macOS 系统凭据存储；系统后端不可用时明确失败，不改存明文。开启笔记后发送已保存定稿、相关课件解读、相关页面图像和已有笔记；撤回课件许可后不再发送页面图像。音频不会发送，应用关闭框架 tracing。后台在每次实际模型请求前重新检查相应许可，包括框架内部的多轮调用；关闭许可停止后续请求，迟到结果不保存，已经发送的内容无法撤回。

自动笔记在有成功保存的定稿时开始，正常更新间隔至少 30 秒；停止保存后处理剩余来源，不等待最低字幕条数。失败或取消暂停自动任务，点击“更新笔记”可继续。草稿、重新打开但尚未确认的原文、未成功保存的版本不参与发布。旧笔记记录课件/字幕来源和版本；直接引用变化显示“来源已变化”，相关新讲述显示待核对，模型必须处理本批旧笔记后才能发布。词项检索与最近讲述复核无法保证发现所有跨语言或远距离纠正，内容仍需核对。个人编辑会锁定条目，后续模型不得覆盖；引用过期时仍保留个人文字和提示。

点击引用可查看对应课件页，或定位录音的估计时间，不自动播放。视觉解读引用明确标为“模型视觉解读”，不可冒充原文。课后整理使用受限 Deep Agents，可选择已有笔记章节；提问通过课程检索、带页内范围的读取和受限原页重读工具获取证据。工具只接收当前课程已知来源 ID，不能读取任意文件。笔记和课后任务最多 12 次模型请求、64,000 tokens（含保守预留）、16,000 UTF-8 字节文字输入；每次最多两张图片、2,048 输出 tokens。图片单独计入容量与 token 预留，不将 base64 长度计作文字输入。上限是工程预算，不是服务商费用报价；用量缺失时显示不确定预留，失败不自动重试。

完整读课件使用按页数确定的独立预算：每页最多一次模型请求、8,192 输出 tokens，顺序执行，不受课后工具循环的 12 次上限限制。模型报告达到输出长度上限时拒绝保存，不能标为成功。当前每份原件最多 64 MiB，每课程最多 1,000 页，原生文本总量最多 4 MiB；每张 PNG 最多 4 MiB、约 419 万像素，渲染缓存最多 256 MiB。达到限制时明确提示按章节导入，不截断课件后标为读完。候选术语最多保存 200 项，达到该数量仍继续读取剩余页面并报告未纳入的候选数量。这些容量限制不代表已验证的进程内存峰值。

旧笔记按内部预算拆成小批次，每批最多核对两条，业务输入最多 7,500 UTF-8 字节，为模型说明和工具定义留出空间。未处理笔记保留待核对的新证据，不因原文已在前一批处理就丢失老师的纠正。自动更新继续处理剩余条目；课后整理在同一请求预算内逐批保存，取消或超额保留已完成批次。删除补丁与修改补丁都只允许操作本批提供的旧笔记。单条笔记及证据自身超限时明确提示，原内容保留，不静默截断。

录音旁的 `knowledge/manifest.json` 保存课程稳定 ID、审核上下文和许可；实际录音使用的快照仍在 `session.json` 的 settings。`knowledge/state.sqlite` 维护可重建的来源版本、笔记与处理状态，数据库连接按事务关闭，不取代录音保存。任务审计只保留有限的来源版本元数据，不重复保存整份课件和全文。导出 `课堂笔记.md` 包含有效 AI 笔记和个人编辑；待核对或失效 AI 内容不作为当前结论导出。

重命名、移动、最近删除和退出先停止自有课程后台；外部移动或替换后拒绝迟到结果，重新打开恢复。录音移到其他文件夹仍引用原课程，只有“使用此课程”才重新关联，并关闭本段云端笔记许可。课程缺失或原件/缓存损坏时暂停云任务，旧笔记保留，可恢复资料或重新关联；已保存的字幕与录音继续可用。永久删除课程资料时，若其他录音（包括最近删除中的录音）仍引用它，则阻止删除，不扩大删除范围。

课件副本缺失或损坏时，重新导入完整的同一文件会校验并恢复原件；有效文本缓存继续复用，不重新解析。当前课件缓存位于 `materials/<材料哈希>/snapshots/<快照 ID>/`，页面图像在其中的 `pages/`，完整渲染 manifest 核对每页次序与校验值；旧版无快照描述的数据仍兼容 `materials/<材料哈希>/` 布局。解读按页存于 `readings/`，避免每读一页重写整份课件。损坏或版本不符的派生缓存需重建/重读，原件和有效解读保留；版本和引用校验仍执行。

## 显示

字幕连续排版，原文状态显示为“优化中”或“已定稿”。未定稿原文使用较淡颜色，真实模型修订立即替换文字；定稿后恢复正常亮度。新增原文和译文逐步显示，最长约 320 毫秒追上最新内容，不积压旧动画。完整结果立即参与翻译、复制和保存；历史录音直接显示全文，减少动态效果时关闭逐字呈现。

玻璃区域使用大范围柔化、降低背景贡献的桌面壁纸着色，而非实时透视其他窗口。共享材质以 RGB8 输出，并加入固定的微量噪声减轻渐变色带；不代表显示器链路色深验证。内容区的两个上角由同一外框绘制，标题与正文共用边界。黑白主题只改变颜色，保持相同布局、间距和圆角。悬浮字幕保留原文、已有译文和关闭入口，可拖动窗口背景移动。

## 常用交互

- 字幕默认跟随最新内容；向上滚动后暂停跟随，点击向下箭头回到最新字幕。
- “设置 → 常规 → 减少动态效果”关闭界面动画与平滑滚动，仍保留字幕自动跟随。
- 音频来源用图标与“系统音频 / 外部输入”区分：系统音频录制电脑播放的声音，外部输入录制所选麦克风或虚拟输入。聆听时可直接切换；暂停时选好来源，继续后生效。加载模型、暂停/继续的过渡和收尾期间暂不可切换。
- 开始按钮左侧显示所选来源的音量；开始前显示“开始后显示”，不额外打开音频设备。刷新成功短暂显示对勾，未找到设备或来源失效会提示。
