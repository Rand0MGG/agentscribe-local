# AgentScribe

### 在你的电脑上听懂课堂：本地推理，双语字幕，完整留下讲解。

外语课堂最需要的是看清老师说了什么、理解整句话的意思。AgentScribe 使用本地语音识别与翻译模型，结合持续修订、语义分句和上下文翻译，让你一边听、一边看双语字幕；课后还能回听原声、查阅字幕。

**模型在你的电脑上运行，录音留在你手里。** 适合外语课程、线上讲座和需要回顾的讨论。

**[下载 Mac 预览版](https://github.com/Rand0MGG/agentscribe-local/releases/tag/v0.6.0-beta.1)** · **[Windows 源码安装](docs/WORKSPACE.md#windows-源码安装)** · [使用指南](docs/WORKSPACE.md)

Mac 下载提供 Apple Silicon DMG；Windows 目前需要按指南安装源码，尚无独立安装包。

## 为什么选择本地推理？

**一整堂课，不用盯着云端转写额度。** 本地识别与翻译不调用按时长收费的云端接口。模型准备好之后，日常字幕不需要购买云端转写分钟数；使用的是你自己的电脑算力。

**网络不稳定，也能继续听课。** 完成首次环境和模型下载后，核心字幕功能可以断网运行。识别和翻译不用等待音频上传、服务器处理再返回；实际速度取决于你的硬件与模型。

**私人讲解与讨论，留在自己的电脑。** 核心识别与翻译不上传音频或字幕。录音、原文和译文保存在本地，你可以自己备份、整理和导出。

**识别模型由你选择。** 支持 Qwen3-ASR 与 Whisper，翻译也可使用本地模型；可以按语言、设备和实际效果选择，而不必把课堂内容交给一个不可选择的远程引擎。

| 你关心的事 | AgentScribe 的本地字幕 |
| --- | --- |
| 课堂突然断网 | 模型准备完成后，识别与翻译仍可运行 |
| 长时间上课是否消耗云端额度 | 核心字幕不消耗云端转写分钟数 |
| 音频是否要发送给服务商 | 本地识别与翻译不上传音频 |
| 课后还能不能拿到资料 | 本地录音、双语 TXT / SRT，可以自己保存和备份 |

本地推理需要兼容的 GPU、模型下载空间和首次准备。可选课程助手的云端阅读与笔记另行配置、另行授权，和本地字幕分开。

## 准确性，靠模型，也靠如何处理整句话

课堂里有长句、停顿、专业名词，也有老师说到后面才补全的意思。AgentScribe 把准确性作为核心目标，围绕这些场景处理字幕：

- **给识别结果纠正的机会。** Qwen 流式识别会根据后续音频修订先前文字；预览与定稿区分显示，早期猜测不会直接被当成最终答案。
- **按语义整理句子。** 结合识别确认与上下文分句确定字幕边界，让翻译处理连贯的内容；长句和复杂停顿仍可能需要人工核对。
- **译文跟着原文更新。** 原文修订会更新翻译请求，旧结果不会覆盖已经变化的原文。HY-MT2 等支持上下文的翻译模型可以参考已经确认的邻近讲述，帮助处理指代与句意。
- **把课程术语带进识别。** 可选 Beta 课程助手从课件提取候选术语，用户审核后用于下一次 Qwen 识别，让课程背景成为模型输入；效果需要结合你的课件与音频验证。

准确性最终要看真实课堂表现。现有验证包含文件推理和字幕修订一致性检查，尚无与讯飞、有道等产品在相同音频、相同语言条件下的准确率对比；我们不把本地运行或短样本结果当作全面胜出的证明。[查看测试范围](docs/VALIDATION.md)

## 上课时跟得上，课后还能找回来

**听外语，原文和翻译一起看。** 从麦克风或配置好的系统音频输入生成字幕，可以同时看原文与译文，也可以只看原文。识别过程中字幕会继续修订，帮助你跟上正在进行的讲解。

**看课件时，也能看到字幕。** 打开可拖动的悬浮字幕，把它放在课件或视频窗口旁，不用来回切换整个应用。

**没听清的地方，留着慢慢听。** 音频和字幕自动保存。课后从文件夹打开录音，拖动播放进度回听；临时离开可以暂停，再继续同一份录音。

**把课堂内容带走。** 定稿可以导出为双语 TXT 或 SRT，用来复习、整理资料或配合录音阅读。录音按文件夹管理，误删后可以从“最近删除”恢复。

## 开始你的第一段录音

1. **准备一次模型。** 在设置中完成环境准备，下载并选择识别与翻译模型。
2. **选好声音与语言。** 选择音频来源、原文语言和目标语言，新建并命名录音。
3. **点击“开始聆听”。** 看双语字幕；结束时停止录音，之后随时打开回听或导出。

遇到模型准备、声音来源或保存问题，查看 [安装与使用指南](docs/WORKSPACE.md)。字幕与翻译的效果取决于模型、语言和音频质量，重要内容请结合原声核对。

## 课件也能参与进来 · Beta

导入 PDF、幻灯片、文档或网页，让课程助手逐页阅读静态课件、提取候选术语。审核后的术语可用于下一次 Qwen 识别；课堂笔记可以附带课件与字幕来源，方便回到原文核对。

在“设置 → 常规”开启“体验 Beta 功能”后试用，默认隐藏。课件阅读和 AI 笔记需要配置云端服务并分别授权；真实课件理解与笔记质量仍待验收。支持格式、准备步骤和使用边界见 [课程助手指南](docs/WORKSPACE.md#课程资料与笔记)。
